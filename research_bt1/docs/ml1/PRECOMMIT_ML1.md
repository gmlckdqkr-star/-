# PRECOMMIT ML1: 비선형 기계학습 경로, 결과를 보기 전에 고정 (2026-11-04 14:58Z)

BT1 대탐색(문턱 원자 조합)과 FC1(선형 예측 결합, 실패)에 없는 방식: 신호 사이의 비선형 상호작용을 모델이 스스로 배우게 하고, 해마다 과거 자료로만 다시 학습한다. 사용자 요청("방법, 방식, 조합 모두 바꿔가며")에 따른 추가 경로.

## 1. 자료
- FC1과 같은 월말 신호(fc1.monthly): F_new(새 48), F_all(111 = 새 48 + 기존 60 + 가격 3), F_allx(222 = F_all + 12개월 변화).
- 목표: 다음 달 S&P 500 TR 로그 초과수익 y (회귀) 또는 y>0 (분류). 두 시대 같은 목표.

## 2. 모델 4종 (하이퍼파라미터 고정, 조정 없음)
- logit: L2 로지스틱 회귀 C=0.1, 분류. 학습 창 안의 평균·표준편차로 표준화, 결측 0(표준화 뒤), 학습 창에서 관측 비율 60% 미만 신호는 그 해 제외.
- ridge: 능형 회귀 alpha=10, 회귀. 표준화·결측 처리는 logit과 같음.
- gbm: LightGBM 분류, 나무 200, 학습률 0.03, 잎 7, 잎 최소 30, 특징 비율 0.5, 표본 비율 0.8(매 반복), seed 1, 결측은 모델 기본 처리.
- rf: 랜덤 포레스트 분류, 나무 300, 깊이 4, 잎 최소 20, max_features sqrt, seed 1, 결측은 학습 창 중앙값으로 채움.

## 3. 학습·예측 (과거만)
- 매년 1월 결정 전에 다시 학습: 학습 쌍 (x[k], y[k+1]) 중 y의 달이 전년 12월 이하인 것만. 학습 쌍 240개 이상일 때부터 예측.
- 점수 = 예측 확률(분류) 또는 예측 수익(회귀). 점수의 확장 백분위(과거 60개 이상) → 대응 Q1~Q4 (FC1과 같음: Q1 3배/1배, Q2 3배/1배/현금, Q3 3배/현금, Q4 3배/1배/현금/−1배). 점수 없는 달은 1배.
- 시도 수 = 4 모델 × 3 묶음 × 4 대응 = 48개.
- 집행·비용: BT1/M1 엔진(bt1_evaldec) 그대로.

## 4. 판정
- 발견 540개월(1955~1985 S&P + 1986~1999 NDX)로 48개 전체 SPA·RW·DSR. 경로 간 정직성: BT1 경로가 4개(mega, FC1, 패자 구조, ML1)가 되었으므로 모든 경로의 통과 문턱을 SPA p < 0.05/4 = 0.0125로 더 엄격하게 둔다(mega 포함, 결과를 보기 전).
- 1순위 = 발견 1배 대비 연환산 로그 우위 최대. 상위 5개 2000~2014 1회 확인, 조건 (iii), G1(trials = BT1 전체 시도 수), 1순위 MS1.
- 모두 넘는 후보만 지연·비용 스트레스로.
