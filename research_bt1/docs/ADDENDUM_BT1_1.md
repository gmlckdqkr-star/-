# ADDENDUM BT1-1: 수억 개 규모 탐색과 규칙 형태 확장 (2026-11-04 13:45Z, 결과를 보기 전)

사용자 지시(13:29Z): "조합만 바꾸지 말고 수억 단위로 방법·방식·조합 모두 바꿔가며 찾기". 그래서 PRECOMMIT_BT1 §2의 생성기(약 23만 개)를 아래 대량 생성기로 **바꾼다**. 이 시점까지 계산한 것은 엔진 일치 시험(M1 엔진과 차이 0)과 속도 측정뿐이고, 어떤 규칙의 성과도 보지 않았다.

## 1. 규칙 형태 5가지 (code/bt1_mega.py)
- BOOL: 원자 1~3개 논리식(M1과 같은 구조 7가지). 새 원자가 최소 1개 들어간다.
- SWITCH: 국면 원자 a가 참이면 b, 거짓이면 c를 따른다.
- VOTE: 원자 3·5·7개 중 m개 이상 참이면 켜짐(m은 1..k 균등).
- LADDER: 원자 2개. 둘 다 참 / 하나만 / 둘 다 거짓에 따라 3단 노출.
- VOTELADDER: 원자 3·5·7개 개수 c. c ≥ m1이면 1단, c ≥ m2이면 2단, 나머지는 3단.
- 노출: 2단은 M1 모양 7개. 3단은 사다리 7개(3/1/현금, 3/2/1, 2/1/현금, 3/1/−1, 3/현금/−1, 1/현금/−1, 3/2/현금). 최소 보유 {1,5,21}일.
- 원자 추출: 슬롯마다 새 45%, M1 기존 비-C3 30%, C3 25%(C3 안 비중은 M1과 같음). 한 규칙 안 원자는 서로 다른 원시 신호. C3 원자만으로 된 규칙은 만들지 않는다(G1 규칙 2).
- 형태 추출 비율: BOOL 30, SWITCH 15, VOTE 20, LADDER 15, VOTELADDER 20(BOOL은 새 원자 조건 때문에 실제 비율이 조금 낮다. 실제 개수를 보고한다).
- 조각(shard) s의 규칙은 난수 rng([20261105, s])로 정해진다. 조각 0은 새 원자 단일 규칙 전부(6,668 × 7 × 3 = 140,028개)로 시작한다.

## 2. 규모와 멈춤 규칙 (결과와 무관하게 미리 정함)
- 조각 1개 = 200만 개. 목표 150조각 = **3억 개**.
- 멈춤: 150조각을 마치거나 **2026-11-05 02:00Z**가 되는 쪽이 먼저. 그때까지 끝난 조각만 쓴다. 조각별 성과는 돌리는 동안 보지 않는다(기록에 시간만 남김).
- 모든 시도는 디플레이션 N에 들어간다.

## 3. 통계 (M1과 같은 정의, 흐름 계산)
- 화면 지표·앞기간·순위 규칙은 PRECOMMIT_BT1 §3과 같다.
- SPA: 전체 규칙의 540개월 차이 흐름. 정상 부트스트랩(m1_stats.stationary_counts, 시드 20261104, 1,000회, 평균 블록 3개월). 학생화 consistent/lower/upper 최대값을 조각별로 구해 합친다. 수학적으로 전체 행렬로 한 번에 계산한 값과 같다.
- Romano–Wolf: 반복마다 상위 50개를 보관한다(열 사전 걸러냄은 정확함: 최종 상위 50에 들 수 있는 열은 빠지지 않음). 50개 넘게 기각되면 그 사실을 적는다.
- 유효 N: Li–Ji(540×540 그람 행렬 누적, 정확). ρ 군집 유효 N은 이 규모에서 계산하지 않는다.
- DSR: 단면 Sharpe 분산은 전체 규칙의 흐름 누적값으로 구한다. N은 전체·고유(64비트 흐름 해시)·Li–Ji 세 가지로 적는다.
- 후보 보관: 조각마다 활성 날 우위 상위 2,000개와 t 상위 2,000개(흐름 포함). 최종 상위 20개(서로 다른 노출)는 앞기간 우위 순위로 고르고, 2000~2014 실제 NDX 확인은 딱 한 번 한다.
- 판정 기준(P30·IMP·G1)은 PRECOMMIT_BT1 §4 그대로다.

## 4. 디플레이션 비용 (미리 적어 둠, 추론)
- 독립 정규 가정에서 최대 t의 기대값은 √(2 ln N)이다. 24만 개면 약 4.98, 1억 개면 6.07, 3억 개면 6.25다. 실제로는 규칙끼리 상관이 커서 이보다 낮다(M1: 24만 개에서 귀무 최대 t 중앙값 3.94).
- 그래서 규모를 키우면 통과 문턱이 오른다. 규모를 키워 얻는 것은 '찾을 기회'이고, 잃는 것은 '같은 신호의 통과 가능성'이다.
