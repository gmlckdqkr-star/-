# ADDENDUM BT1-3: 상위 규칙 묶음(앙상블) 2개 추가, 경로 간 문턱 강화 (2026-11-04 15:10Z, 대탐색 결과를 보기 전)

## 1. 이유
FC1·ML1에서 발견 기간 1순위가 1986~1999 상승장의 3배 비중 덕을 본 뒤 2000~2014에 무너졌다. 한 규칙만 고르면 선택 잡음이 크므로, 대탐색이 끝나면 미리 정한 순위의 상위 규칙들을 날마다 '중간값 노출'로 묶은 것도 한 번만 확인한다. 시도 수 +2.

## 2. 정의 (결과를 보기 전 고정)
- BAG50: 기본 순위(활동일 우위, 서로 다른 흐름) 상위 50개 규칙. BAGT20: t 순위 상위 20개 규칙.
- 날마다 각 규칙의 결정 상품을 노출로 바꾼다: 3배=3, 2배=2, 1배=1, 현금=0, −1배=−1. 중간값을 내림(보수적으로 낮은 노출 쪽)해 다시 상품으로 바꾼다. 규칙이 비활성인 날은 그 규칙의 1배(=1)로 센다(bt1_path와 같음).
- 집행·비용·지연은 BT1 엔진(bt1_evaldec, 지연 2일, 한쪽 0.3%) 그대로.
- 판정: 2000~2014 NDX 1회 확인(1배 대비, s0.85 대비, 조건 (iii)), G1(trials = BT1 전체 시도 수), MS1 대표값. 발견 기간 숫자는 구성 규칙이 발견 자료로 뽑혔으므로 참고로만 적는다.

## 3. 경로 간 문턱
BT1 경로는 mega, FC1, 패자 구조(KL1), ML1의 4개다. 모든 경로의 SPA 통과 문턱을 p < 0.05/4 = 0.0125로 둔다(PRECOMMIT_ML1과 같음, mega 포함).
