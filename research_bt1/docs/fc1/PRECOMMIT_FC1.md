# PRECOMMIT FC1: 예측 결합(연속 가중) 경로, 결과를 보기 전에 고정 (2026-11-04 14:45Z)

BT1의 독립 비평가가 "빠진 방식"으로 꼽은 것: 문턱 규칙(원자 조합) 대신, 신호마다 과거 자료로 부호·크기를 배운 단순 예측 회귀를 만들고 그 예측을 평균내서(Rapach–Strauss–Zhou 2010) 연속 점수로 레버를 정하는 방식. BT1 대탐색(mega)과 다른 방식이라 별도 경로로 둔다. idea_check는 E02(정적 켈리 혼합)와 낱말이 겹쳤지만, E02는 고정 비중이고 이 경로는 매달 바뀌는 예측이다. 새 정보 종류(BT1 새 원시 신호 48개)가 들어가므로 E02의 다시 열 조건과 별개로 진행한다.

## 1. 자료 (BT1과 같음, 2014-12-31까지)
- 원시 신호: BT1 캐시 prim.npz(M1 기존, DROP 3개 제외, gwz_ep·gwz_dp는 ADDENDUM_BT1_2의 시점 정합판) + prim_bt1.npz(새 48개). 하루 단위 값은 이미 발표 지연이 반영된 계단 값이다.
- 가격 신호 3개 추가: S&P 500 TR 12개월 로그 추세, 1개월 로그 수익, 252일 실현 변동성(로그).
- 예측 대상: 다음 달 S&P 500 TR 월간 로그 초과수익(무위험 금리 차감). 두 시대 모두 같은 대상(긴 기록).

## 2. 방법 (모든 값은 그 달 말 종가까지 알려진 것만)
- 월말 = 달력의 그 달 마지막 거래일. 신호 x[m] = 월말 값(pos 종류는 로그).
- 신호마다 확장 창 단순 회귀 y[k+1] = a + b·x[k] (k+1 ≤ m인 쌍만), 쌍 120개 이상일 때 예측 f_i[m].
- 결합 3종: 평균, 중앙값, DMSPE(θ=0.9, 할인 평균 제곱 오차의 역수 가중, 표본 밖 오차 60개 이상인 신호만). 유효 신호 5개 미만이면 점수 없음.
- 점수 2종: S1 = 결합 예측, S2 = 결합 예측 ÷ 자기 지수 252일 분산(월 환산; 켈리 모양). 자기 지수 = SPX 시대 S&P TR, NDX 시대 1985-10-02부터 NDX(M1 own_index와 같음).
- 점수의 확장 백분위 p[m] (과거 유효 점수 60개 이상). 대응 4종:
  - Q1: p≥.5 → 3배, 아니면 1배
  - Q2: p≥.7 → 3배, p≥.3 → 1배, 아니면 현금
  - Q3: p≥.5 → 3배, 아니면 현금
  - Q4: p≥.7 → 3배, p≥.3 → 1배, p≥.1 → 현금, 아니면 −1배
  - 점수·백분위가 없는 달은 1배.
- 신호 묶음 3종: P_new(새 48개), P_all(새 48 + 기존 + 가격 3), P_allx(P_all + 각 신호 12개월 변화).
- 시도 수 = 3 묶음 × 3 결합 × 2 점수 × 4 대응 = 72개. 전부 센다.
- 집행: M1/BT1 엔진과 같음(월말 결정 → 지연 2일, 한쪽 0.3%, 3배 비용 2.45%/년, 현금 = 금리−2%, 15.4% 과세). 검증: bt1_evaldec가 BT1 화면 엔진과 월간 차이 1.2e-7로 일치(규칙 50개).

## 3. 판정 (발견 1955~1985 S&P + 1986~1999 NDX, 540개월)
- 72개 전체 SPA(일관·하한·상한, 정상 부트스트랩 B=1000, 평균 블록 3개월, 시드 20261104) + Romano–Wolf + DSR(N=72와 N=BT1 전체 시도 수 둘 다 표시).
- 경로 간 정직성: BT1 경로 3개(mega, FC1, 패자 구조) → FC1 SPA p는 0.05/3 = 0.0167 아래여야 "통과".
- 미리 정한 1순위 = 발견 기간 1배 대비 연환산 로그 우위 최대. 상위 5개를 2000~2014 NDX로 한 번만 확인(1배 대비, s0.85 대비, 조건 (iii): 확인 d>0 이고 발견 d의 절반 이상).
- G1 관문(gate.test): 신호 = 3배 결정 또는 준비 기간. trials = BT1 전체 시도 수(가장 엄격). 원 적중률과 N=72 보정도 같이 적는다.
- MS1: 1순위의 대표값(0.1616 + 흐름 차이 중앙값)과 실제 경로 행. 30%(사용자 기준) 및 16.16%(s0.85) 비교.
- 위 조건을 모두 넘는 후보만 지연 +1~5일·비용 2배 시험으로 간다.

## 4. 고정 사항
- 위 숫자(120, 60, θ, 문턱, 묶음, 대응)는 바꾸지 않는다. 바꾸면 ADDENDUM으로 적고 시도 수를 늘려 센다.
- 2014년 이후 자료·holdout 파일·금지 파일은 열지 않는다. 신호 선택은 문헌 기반이라 2000년대 논문 지식이 섞였을 수 있다(M1과 같은 한계, 보고서에 적음).
