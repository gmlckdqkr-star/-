# LH1 결과: 1929~1954 미국에서 v1 금리 경보 진실 시험 (2026-11-12)

사전 등록 PRECOMMIT_LH1.md (sha c42c3057…) + ADDENDUM_LH1_1.md (sha 5f03d38a…, rf = rate_known_pct) 그대로 실행. 2015년 이후 행·XV1 파일·금지 파일은 읽지 않음. lab 사용: 아니오 (이유: 1955년 이전 자료·MS1 엔진(std.py) 직접 사용).

## 결론
- 최종 판정: **불분명 (단기금리 자료에 따라 달라짐)**. 주 자료 A(미국 단기 국채, NBER m13029a)는 "불분명", 민감도 B(기업어음, NBER)는 "통함"이다. 사전 규칙상 둘이 다르면 최종은 불분명이다.
- 기록 정정: "1929년에 v1 금리 경보가 아무 경고도 안 했다"(c3_relax / crash_overlay 핵심 위험)는 **자료 빈칸 때문**이었다. 1934-02 전 3개월 금리가 비어 있어 경보가 구조상 켜질 수 없었다(기록 재현 REC: 경보 켜짐 0%, v1 −0.6%/년). 두 자료 모두 1928-05부터 경보가 켜져 1929년 폭락 전 내내 켜져 있었다.
- 그래도 v1은 1929년 폭락을 크게 맞았다. 경보는 켜져 있었지만 v1은 200일 추세 이탈 때만 나가므로 1929-10 말에야 빠졌다(9월 3배, 10월 평균 2.1배, 11월 0). 경로 최대 낙폭 A −87.5%, B −83.3%.
- 방법 변경 없음. 계획 수치는 MS1 경로 15.2% 그대로. 30% 기준과는 무관한 검증 시험이며, 30%로 가는 길을 찾은 것이 아니다.

## 결과 (경로 하나, 세후 기하 연복리, 쉬는 돈 이자 0, 채점 1929-03-15 ~ 1954-12-31, 6,446행)
| 계좌 | A (국채 단기) | B (기업어음) |
|---|---|---|
| v1 실제 경보 | **7.2%** (MDD −87.5%) | **10.5%** (MDD −83.3%) |
| 위약 중앙값 (92회, p10 / p90) | 2.6% (−1.7 / 9.7) | 2.4% (−3.0 / 9.6) |
| S = v1 − 위약 중앙값, p | +4.6%p, p 0.28 → 불분명 | +8.2%p, p 0.065 → 통함 |
| 경보 켜진 비율 | 9.9% | 17.7% |
| 1배 보유 | 6.2% (MDD −83.7%) | 같음 |
| 3배 보유 | −2.8% (MDD −99.9%) | 같음 |
| ALWAYS (추세 이탈 항상 따름) | 10.4% (MDD −78.1%) | 같음 |
| NEVER (경보 끔) | −0.6% (MDD −85.4%) | 같음 |

- A와 B의 차이는 한 가지다. 1931-10 영국 금본위 이탈 뒤 연준 금리 인상으로 기업어음은 1931-11~1932-02에 다시 장기금리 위로 올라갔고(경보가 1933-10까지 유지, 1931-32 마지막 폭락을 피함), 국채 단기는 그러지 않았다(경보가 1931-09-29에 꺼지고 v1이 1931-10~1932-06에 1~2.3배로 다시 들어가 마지막 폭락을 맞음).
- 하위 구간 (A): 1929-03~1932-12 v1 −29.8%/년 (1배 −25.0, ALWAYS −17.9) / 1933~1945 v1 6.0% (1배 13.1) / 1946~1954 v1 33.0% (1배 14.7). B: 같은 순서로 −17.9 / 8.2 / 32.4.
- 굴리는 창 (A, 평균 함정 금지 규칙):
  - 10년 창 187개: v1 p10 −12.5 / 중앙 6.1 / p90 32.9, 1배 −0.1 / 7.2 / 13.3. v1이 1배를 이긴 창 46.5%, 차이 중앙 −0.8%p.
  - 20년 창 67개(시작 1929-03~1934-10, 많이 겹침): v1 −3.5 / 6.5 / 14.7, 1배 2.2 / 8.7 / 11.6. v1 승률 38.8%, 차이 중앙 −3.3%p.
  - 이 시대에서 v1은 흔한 시작일 기준으로 1배 보유보다 나빴다(1955~85 S&P 굴리는 창 결과와 같은 방향).
- 제로금리 구간 Z (1935-08-08 ~ 1954): 경보 켜짐 0% (일본 Q1과 같은 "제로금리에서 경보 침묵"이 미국에도 있었다). 그러나 이 구간에서는 비용이 아니었다: v1 22.1% vs ALWAYS 18.6% vs 1배 10.9%. 즉 "제로금리면 추세 이탈을 항상 따르라"는 보험 후보에 대해 일본은 찬성, 미국 1935~54는 반대 증거다(여기서 후보는 채점하지 않음, XV1 후보 줄에 정보로만 넘김).
- 참고 줄 (판정 아님): AT2 5개국 + Q1 일본 + LH1 A의 Fisher 결합 p = 0.011. 나라 간 금리 순환이 얽혀 있어 과대평가된 값이다.

- C3: 1배 보유 손 계산 6.1743% = 엔진 6.1743%.
- C4: 1954-12-31 다음 행이 계산에 안 들어감(assert 통과).
- 별도 코드 교차 점검(원자료 Shiller GS10 엑셀·TBILL 월값·기업어음 CSV, ov/mkt 코드 안 씀): rate_known_pct = 전월 값(1,495행 일치, 미래 정보 없음). 월별 역전 달: A 1928-04~1929-11, 1930-01~02 / B 1927-06~1930-06, 1931-11~1932-02. 여기서 계산한 경보 시작·종료(A 1928-05-01 켜짐 → 1931-09-29 꺼짐, B 1933-10-11 꺼짐)가 엔진 경보 표와 일치.
- 한계: (1) 1934년 전 단기금리는 "3개월 국채"가 아니다(국채 단기물은 1929-12에 처음 발행, A는 국채 노트·증서·단기물 혼합, B는 기업어음). 어느 쪽이 맞는 대리 지표인지 정할 근거가 없어 판정이 불분명으로 남는다. (2) 미국 한 시대·폭락 한 번이라 독립 표본이 작다. (3) 배당은 RECON(Shiller), 1934년 전 rf는 A13에서 현금 이자용 UNUSABLE 판정(여기서는 3배 펀드 조달비에만 쓰임). (4) 연 환산은 252행 기준인데 이 달력은 연 249.9행이라 모든 계좌 CAGR이 약 1% 상대값만큼(7.2 → 약 7.1) 높게 읽힌다. 판정과 순위는 같다.
