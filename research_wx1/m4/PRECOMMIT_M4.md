## 4. 지표·기간·검정
- 화면 지표: 비용 뒤·세전 **월간 로그 성장 차이** d_m = Σ log(1+r_규칙) − Σ log(1+r_1배NDX) (1배 NDX = MS1 1배 보유: r − 0.2%/년; 1986 전은 S&P 총수익 슬롯). 보조: 같은 달의 s0.85 실제 세전 흐름 대비 차이(std.engine tax=0, 1986 전 real_spx_55_85, 뒤 real_ndx_86_14).
- **앞기간(선택) = 1964-01 ~ 1999-12 (432개월)**: 1964-01~1985-12는 S&P 시대(NDX 슬롯 = S&P 총수익), 1986-01~1999-12는 NDX 시대. 1962-01~1963-12는 지표 예열(H.15 국채 자료가 1962-01부터라 1955~61은 넣을 수 없음). 금은 자료가 생긴 1985부터만 고를 수 있음(그 전엔 자격 없음 → 빈자리/현금).
- 앞기간 계산은 2000년 이후 행을 아예 읽지 않는 환경(Env end=1999-12-31)에서 한다. 인과성 점검: 규칙 200개를 1990-12-31에서 잘라 겹치는 달이 같아야 함.
- **SPA (Hansen 2005)**: 전체 N개 모두, 정상 부트스트랩 평균 블록 3개월(= 63거래일), 1,000회, 씨앗 7. 일관(consistent) p를 주 p로, 상·하한 p도 적음. 귀무 = 어떤 규칙도 1배 NDX보다 기대 월 로그 성장이 크지 않다.
- **Romano-Wolf** 학생화 단계 하강 5%.
- **DSR**: 월간 d의 샤프, N = 14,608 (주), 유효 N 두 가지(상관행렬 고유값 참여비 PR, ρ ≥ 0.9 대표 군집 수)도 같이. 판정에는 N 전체를 쓴다.
- 보조 SPA/RW: s0.85 대비 행렬(같은 부트스트랩). 판정은 아니지만 's0.85를 형식적으로 이기는 규칙이 있는가'를 그대로 적는다.
- **뒷기간 1회 확인 = 2000-01 ~ 2014-12**, 앞기간 평균 d(1배 대비) 상위 20개만(SPA 통과 없어도 20개). s0.85 대비 월 평균 d > 0 이고 앞기간 s0.85 대비 d의 50% 이상이어야 함(앞기간 s0.85 대비 d ≤ 0이면 자동 실패). 감쇠(뒤/앞)를 그대로 싣는다.

## 5. 판정 (상위 §3 그대로)
- **P30** = (1) 대표 환산 ≥ 30.0% (2) SPA 일관 p < 0.05 + RW 5% 안 + DSR(N 전체) ≥ 0.95 + 뒷기간 확인 통과 (3) 실제 NDX 1986~2014 s0.85 대비 ≥ −0.5%p, 실제 S&P(1970~85, 자료가 되는 S&P 시대) ≥ −0.5%p (4) dd80 ≤ 73%.
- **대표 환산** = 16.2 + d_stream, d_stream = 후보 일간 세전 흐름(1964~2014)과 s0.85 실제 세전 흐름을 같은 lab measure_series 방식(dev250_path 색인 행렬, IS1 세금, turnover 1)으로 재표본한 경로별 짝 차이 중앙값. 후보 자신의 measure_series 값(진짜 s0.85 16.2 대비)과 s0.85 흐름 재표본 값(28.3%)도 함께 싣는다. 실제 NDX·S&P 세후는 lab ms1eng 커널(MS1 세금)로 여러 상품 비중을 그대로 돌려 같이 싣는다.
- **IMP** = (2)~(4) 통과 + 대표 환산 d ≥ +1.0%p.
- MS1 행은 뒷기간을 통과한 것만, 없으면 앞기간 1위 1개를 '실패 참고'로 잰다.
- 통과 0이면 소진 기록(A45)을 쓴다.
