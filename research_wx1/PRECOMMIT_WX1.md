## 3. 판정 (모든 레인 공통)
**통과(P30)** = 아래 전부:
1. 대표값 ≥ 30.0%.
   - 경로 재계산이 되는 후보(나스닥 가격·금리·macro(k)만 읽음): MS1 dev250_path 30년 세후 중앙값.
   - 외부 비가격 시계열·종목 신호를 읽는 후보: **대표 환산 = 16.2 + d_stream**. d_stream = 같은 '수익 흐름 재표본'(lab ms1.measure_series) 기준에서 후보 − s0.85(실제 역사 일간 흐름을 같은 방식으로 재표본)의 경로별 짝 차이 중앙값. s0.85의 흐름 재표본 값도 함께 싣는다. (흐름 재표본은 거시 경보를 원래 날짜에 붙이는 것과 같아 s0.85에게도 후하므로, 짝 차이로만 환산한다.)
2. 선택 디플레이션 뒤에도 1을 만족: 대량 탐색은 (i) 앞기간 SPA(Hansen 2005, 정상 부트스트랩 평균 블록 63일, 1,000회) p < 0.05 그리고 Romano-Wolf 단계 하강 5% 안에 들 것, (ii) DSR(Bailey–López de Prado, N = 그 레인 전체 시도 수, 상관 군집으로 낸 유효 N도 같이) ≥ 0.95, (iii) 뒷기간 1회 확인에서 s0.85 대비 d > 0 이고 앞기간 d의 50% 이상. 소규모(≤50개) 후보는 MC1 깎기(N≤10 3%p, 11~50 5%p, >50 8%p) 후 값으로 1을 본다.
3. 실제 NDX 1986~2014 d vs s0.85 ≥ −0.5%p, 실제 S&P 1955~85(신호 자료가 있으면) d ≥ −0.5%p.
4. dd80(경로 −80% 도달 비율) ≤ s0.85의 73%.

**개선(IMP)** = 2~4 통과 + 대표(또는 환산) d ≥ +1.0%p. 30%는 못 넘어도 실제 프로그램에 쓸 가치가 있는 것.
나머지 = 실패. 정보 관문 G1(research/breakthrough/INFO_GATE_KO.md)은 시점 신호의 1차 거르개로 함께 적는다.
