## 1. 주 관례(PRIM)와 시험 관례
- PRIM: DF5 중립 패널(DF5 df5data.panel raw=False: 금 초과수익 0, 장기국채 초과수익 0 + 이표, S&P·나스닥 원자료) + 추세 초과수익을 세계마다 그 세계 대용 평균의 50%로 평행 이동(분산·상관은 그대로).
  상품: DBMF = rf + 추세 − 0.85%, RSST = S&P 총수익 + 추세 − 0.99%, GDE = 0.9 S&P + 0.1 rf + 0.9(금 − rf) − 0.20%, GLD = 금 − 0.40%, TLT = DF5 LTT, QLD = DF5.
- Q(탈락 시험): 중립 패널 + 추세 25%. RAW(원자료 패널 + 추세 100%)·ZERO(중립 패널 + 추세 0%)는 보고만.

## 3. 관문과 강건성 (DF5·DF6와 같은 정의, PRIM에서)
- G1 실제(REAL): 연복리 > QQQ, |MDD| ≤ 0.9 × |QQQ MDD|. G2~G5(P30, P10, X30, X10): 짝 비교 중앙값 > 0, 중앙값 > QQQ, p10 연복리 ≥ QQQ p10, |p10 MDD| ≤ 0.9 × QQQ.
- 강건성(G1~G5 통과만): H1 비용 2배(QQQ도) REAL·P30·X30 유지. H3 P125 30년 G2 조건. H4 이웃: F1·F2는 같은 계열에서 비중 최대 변화 ≤ 0.1인 점
  4개 이상, 그중 75% 이상 G1~G5 통과. F3는 같은 켜짐·꺼짐에서 다른 신호도 통과. H5 추세 25%(Q)에서 G1~G5 통과.
- 1등급 = G1~G5 + H1 + H3 + H4 + H5. 2등급 = H5만 실패(추세 수익이 절반 이상이어야 성립).

## 4. 선택과 보고
- 등급 안에서 점수 = min(짝 P30, 짝 X30, REAL 초과). 이웃 점수 = 자신과 이웃(F1·F2: 비중 최대 변화 0.1 이내 같은 계열 점, DBMF 포함; F3: 다른 신호의 같은 켜짐·꺼짐) 점수의 최소. 이웃 점수 최대가 답. 0.05%p 이내 동점이면 최소 낙폭 여유가 큰 것.
- 답(없으면 계열별 최선)의 필요 추세 비율 f*(G1~G5를 통과하는 최소 추세 비율, 0.05 단위)를 보고한다.
- 통과 0개면 0개로 보고한다. 관문은 고치지 않는다.
- 보고: 답·계열별 최선·P2·P3를 PRIM/RAW/ZERO에서 P·X 5/10/20/30년, REAL, P125. 사용자 표는 5/10/20년 연 수익 중앙값 · 하위 10% 낙폭, 실제, QQQ·v1·v2와 나란히.
