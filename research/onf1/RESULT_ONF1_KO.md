# ONF1 결과 (2014년 이전 수치만): 밤/낮 선물 전략(v9~v13) 검증과 대안 탐색

작성 2026-11-10 (병렬 검증 4단계까지의 지적을 반영한 최종판). 이 파일에는 2015년 이후 성과 수치가 없습니다(MNQ 1계약 금액처럼 지금 시세로 계산한 운용 사실만 있음). 2015년 이후 수치가 들어간 전체 보고서, 검증 기록, 그 수치를 내는 코드는 `research/onf1/holdout/` 에 있으며 전략을 설계·선택하는 스레드는 열지 않습니다.

용어: **v1** = s0.85. 기준값은 MS1 **대표**(dev250_path, 가상 30년 500개 중앙값) 16.16%, **실제**(real_ndx_86_14, 나스닥100 1986~2014 한 경로) 31.08%. **v9·v10·PRESET_A** = 업로드 전략의 세 설정, "미국만" = 한국 야간 구간 제외. **1bp** = 0.01%, 수수료는 편도. **+0.5 / +1.2%p** 처럼 빗금으로 나눈 두 수 = v1 대비 차이를 대표 / 실제 순서로 적은 것. **브레이크** = 손실이 나면 배율을 자동으로 낮추는 장치. **난수 30개** = 자료가 없는 1999-03 이전의 밤 수익을 무작위로 만들어 넣고 30번 바꿔 평균한 것. 표기: **확인됨** = 직접 실행, **추론** = 원본·계좌로 직접 확인 못 함, **미검증**.

## 결론

1. **업로드 연구의 대표 수익률은 실제 주문으로는 재현되지 않음** (실제 주문 순서 수치: 확인됨. 원본이 그렇게 계산했다는 점: 추론). 원본 백테스트(`plan.py` 52행)가 한국 야간 포지션 크기를 진입 뒤에 끝나는 미국 장 결과로 정함. 전체 기간 수치는 2015년 이후 구간을 포함하므로 holdout 폴더의 전체 보고서에만 적음. 2014년 이전 자료 안에서만 보면(2010-03~2014-12, 프로젝트 기준, 표본 내) 미국만 → 한국 야간 포함(실제 주문 순서)은 v9 39.1% → 21.9%, v10 51.3% → 29.4%, PRESET_A 44.4% → 12.7% 이고, 미래 정보를 쓰는 방식이면 39.0 / 62.8 / 87.9% (`results/kr_dev_le2014.json`).
2. **사전 등록 후보 12개 중 통과 0개 (계산은 확인됨. 1999-03 이전 밤 수익은 자료가 없어 가정).** 규칙 1 = 보수 가정 C 에서 대표와 실제 둘 다 v1 초과(수익률과 짝 비교 모두), 규칙 2 = 수수료 2배에서도 두 기준 v1 대비 플러스. 등록 당시 측정과 보정 측정 모두 0/12. M 가정(1993년부터 프리미엄)에서도 규칙 1·2 를 함께 충족한 후보가 없어, 등록 규칙 4의 "조건부" 후보도 없음. 단, 이 "통과 0" 은 등록한 수수료(편도 0.83bp, 스트레스 1.66bp. 업로드 보고서가 스스로 쓴 기준값과 스트레스 값)에 달려 있음. 같은 규칙을 0.30bp(스트레스 0.60bp)에 적용하면 PRESET_A 미국만이 C 에서 충족하고(난수 30개 중 21개), T5 와 F1 은 M 에서만 충족해 "조건부" 가 됨(30개 중 30개). 유리한 가정을 모두 겹친 최대값(PRESET_A 미국만, M + 계좌 현금 이자 + 0.30bp)도 대표 24.0% 로 실전 기준 30% 에 못 미침.
3. **가장 방어할 만한 탈락 후보는 T5.** 구조: 총자산의 15% 를 선물 계좌(이자 0)로 옮기고 남은 85% 로 v1 을 그대로 운용하면서, v1 이 TQQQ 를 든 날에만 밤사이 MNQ 를 총자산의 1배만큼 더함(v1 이 3배일 때 낮 노출 약 2.55배, 밤 노출 약 3.5배). C 에서 v1 대비 −1.0 / −1.9%p, M 에서 +1.2 / +0.5%p 이나 M 수수료 2배 −2.2 / −3.1%p. 2014년 이전 실제 밤 구간에서는 2001~2014, 2005~2014 가 +1.5~+1.6%p(t 0.5), 1999-03 부터 넣으면 +3.9%p. 겹치지 않게 나누면 1999~2000 에 몰려 있고(+28.8, −0.6, +3.5, +0.9%p), 어느 구간도 유의하지 않으며(t −0.2~1.4), 수수료 2배면 1999~2000 을 뺀 세 구간이 모두 마이너스(+25.1 / −2.8 / −0.6 / −3.2%p). PRESET_A 미국만은 C +0.5 / +1.2%p, M +2.5 / +3.3%p 로 T5 보다 높지만 수수료 2배에서 탈락하고(C −3.0 / −3.5%p, M −1.2 / −1.4%p), 브레이크가 하루 늦으면 C −3.9 / −7.2%p, 이틀 늦으면 C −5.7 / −12.0%p(M −4.1 / −9.6%p)이며, 실제 밤 자료가 있는 2001~2014 에서는 v1 보다 −3.6%p(0.30bp 로도 −0.9%p). (T5 는 T·F 후보 9개의 결과를 본 뒤 2014년 이전 자료만 쓴 반대 논증이 지목한 것. 이 문단은 2015년 이후 자료를 본 뒤에 작성됨: 13:56Z 1회, 이후 수수료별·구간별 추가 계산 1회.)
4. **v1 유지. 프로그램 적용 없음.** 상세 `PROGRAM_SPEC_ONF1_KO.md`.

### 3. 밤 전략에 가장 유리하게 본 경우 (반대 논증)

- 수수료 편도 0.83bp 는 업로드 연구의 가정(v9 보고서 355행: 수수료 2달러 + 거래소 비용 + 반 틱 0.55bp 의 1.5배. 2배 스트레스도 v10 보고서 236행의 값). 공개 수수료·호가 기준 추정은 지금 지수 수준에서 0.14~0.53bp (추론, 계좌 미확인. 계약당 수수료는 달러 고정이라 지수가 낮았던 과거에는 bp 로 몇 배 높았고, 시가·종가 체결 미끄러짐은 재지 않음). 0.30·0.60bp 결과는 위 민감도 표.
- 프리미엄이 없으면(Z, 0.83bp, 1절 표의 마지막 열): T5 −5.8 / −7.7%p, P3 −5.0 / −7.6%p, F1 −11.1 / −12.1%p. 수수료를 0.30bp 로 낮추면 C 기준으로 T5 약 2%p, P3 2~3.5%p, F1 3~4%p 회복(Z 에서는 따로 재지 않음, 추정)이라 프리미엄이 없으면 여전히 마이너스. 손익분기 수수료(편도, 30 seed 직선 보간, 두 기준 중 낮은 쪽): C 에서 T5 0.40bp, P3 0.95bp(브레이크 2일 지연이면 0.30bp 미만), F1 0.30bp 미만, M 에서 T5 0.95bp, P3 1.39bp, F1 0.82bp.
- 1999년 이전 프리미엄 근거: 1993년 이전 미국 지수 밤 프리미엄을 보인 연구 없음. SPY 1993-01~1999-03 밤 +16~18%/년(가격만 / 배당 포함)이지만 당시 호가 단위(1/64~1/32달러)만큼 시가를 낮추면 +4~12%, 1993~95 는 사라짐(1996년 이후만 견고). M 이 넣는 연 11.8% 는 이 범위의 위쪽 끝. 2014년 이전 자료 안에서 프리미엄은 줄어듦 (QQQ 밤 수익 1999~2002 연 +21%, 2003~07 +15%, 2008~14 +8%).
- 추가 시도 2개 (반대 논증, 난수 1개): ① 하락일 뒤에만 밤 포지션: v1 대비 −2.0 / −4.3%p(C). ② v1 매도를 다음 시가로 미룸: +0.4 / +0.8%p(C)이지만 프리미엄이 전혀 없어도 +0.4 / +0.5%p, S&P 시대에서는 0 안팎, 실제 밤 구간 4개 중 2개에서 −1.6%p 라 밤 프리미엄에서 나온 값이 아님. 닫힌 축 X40(OV1-B)과 같은 결과. 둘 다 채택 불가.
- T5 의 밤 포지션은 82~89% 의 날에 들고(하위 구간별 63~94%), 든 날의 크기는 약 0.95배. 대표 기준 MDD 는 v1 보다 약간 깊음. T5 선물 계좌 현금 이자와 배당 반영은 재지 않음(산술로 각각 연 +0.1~0.3%p, +0.4~0.6%p. 수수료 2배 탈락을 바꾸지 못함, 추정).

## 남은 문제

1. 1999년 이전 나스닥100 밤 프리미엄은 자료로 확인 불가.
2. 실제 MNQ 편도 비용(시가·종가 미끄러짐 포함)과 계좌 증거금·이자는 미검증. T5 와 v9 미국만의 v1 대비 부호가 이 비용 범위 안에서 바뀜.
3. 한국 야간 구간은 MS1 로 잴 자료가 없음.
4. 실제 선물 가격이 아닌 ETF 가격 사용. 1999~2004 QQQ 종가는 16:00 동시 가격이 아님. 공급자 간 시가 차이(하루 ±0.5bp)가 T5 우위와 같은 크기.
5. 2015년 이후 자료는 이 12개 후보에 대해 이미 열어 보았음. 앞으로의 기록으로도 T5 를 증명하기 어려움: 2001~2014 의 우위(+1.5%p, t 0.5)가 우연이 아님을 t 2 로 확인하려면 같은 우위가 200년 이상, 1999~2000 을 넣은 구간(t 1.1~1.3) 기준으로도 40~50년 이어져야 함. 다시 검토할 근거가 될 수 있는 것은 비용뿐: T5 가 C 에서 v1 과 같아지는 편도 비용은 0.40bp(1계약 편도 약 3,000~3,300원), 수수료 2배 조건까지 견디려면 0.20bp(약 1,500~1,700원) 이하. M 에서는 0.95bp / 0.47bp. 계좌의 계약당 수수료와 20거래일 동안 16:00:20 ET·09:30:05 ET 의 MNQ 매수·매도 호가를 적어 잴 수 있음.
6. 재지 못한 것: 손실이 큰 날 종가 직후 브레이크 주문의 체결 미끄러짐, PRESET_A 미국만의 정수 계약 운용 성과, T5 선물 계좌 현금 이자.
