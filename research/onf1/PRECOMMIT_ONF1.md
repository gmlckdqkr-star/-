# ONF1 사전 등록 (2026-11-10, 결과를 보기 전에 고정)

대상: 사용자가 올린 밤/낮 선물 전략(v9~v13)의 검증과, 그 안에서 살릴 수 있는 부분(미국 밤 프리미엄)으로 v1 을 넘는 방법 찾기.
자료: 2014-12-31 이전만 (MS1 5기준, research/measure_std/std.py). 2015년 이후는 holdout, 선택에 쓰지 않음.

## 공통 조건
- MS1: dev250_path 가 대표, 신호 지연 2거래일, NDX 가격지수, 연 1회 세금 + 마지막 청산세, v1 과 같은 경로 짝 비교.
- 선물: 내재 금리 = 단기국채 + 0.4%p (MF1 과 동일), 선물 계좌 현금 이자 0, 파생 세금 11% (공제 250만, 이월 없음).
- 밤 포지션 수수료·미끄러짐: 편도 0.83bp (업로드 연구의 가정). 스트레스 2배(1.66bp).
- 밤/낮 분리: 1999-03-10 이후는 실제 QQQ 시가. 그 이전은 합성 (밤 = α + β·일수익 + 잔차, β·잔차는 QQQ 1999-03~2014 추정).
  - C (보수, 판정 기준): 1999-03-10 이전 α = 0
  - M (중심): 1993-01-29 이후 α = 추정값 (SPY 실제 시가로 1993~98 밤 프리미엄이 관측됨), 그 이전 0
  - H (상한): 전 기간 α = 추정값.  Z: 모든 날 α = 0 (프리미엄이 없을 때의 구조 값)

## 후보 (N = 12, 이 밖의 시도는 하지 않음)
P 군 (업로드 프리셋, 미국만, 실거래 순서 엔진 code/eng.py·ms1f.py): P1 v9, P2 v10, P3 PRESET_A
T 군 (v1 TQQQ 그대로 + 별도 선물 계좌에 밤에만 MNQ, code/ntilt.py impl 0; 선물 계좌는 총자산의 φ, 연 1회 재배분):
- T1 τ=1.0 항상, φ=0.15   - T2 τ=0.5 항상, φ=0.075   - T3 τ=2.0 항상, φ=0.30
- T4 τ=1.0, v1 이 현금(배율 0)일 때만, φ=0.15   - T5 τ=1.0, v1 이 보유 중일 때만, φ=0.15
- T6 τ=min(1.0, 0.09/σ²) 항상 (20일 변동성 30% 초과 시 축소), φ=0.15
F 군 (v1 을 선물로 구현(MF1 방식, 매일 재조정) + 밤 가산, impl 1, 현금 이자 0, 연속 계약):
- F1 τ=1.0 항상   - F2 τ=2.0 항상   - F3 τ=1.0, v1 이 현금일 때만
(τ = 밤에만 추가로 드는 MNQ 명목 / 총자산. 증거금 한도: 명목 ≤ 선물계좌 잔고 / (7.5% × 1.6).)

## 통과 규칙
1. C 기준에서 dev250_path 와 real_ndx_86_14 둘 다: 후보 CAGR > v1 그리고 짝 차이 중앙값 d > 0.
2. 수수료 2배에서도 두 기준 d > 0.
3. 통과 후보가 있으면 그중 C 기준 dev250_path d 가 가장 큰 것 1개만 holdout(2015~2026 실제) 을 1회 연다.
4. C 에서 떨어지고 M 에서만 붙으면 "가정 의존(조건부)" 으로만 적고 통과로 세지 않는다.
5. 통과가 없으면 v1 유지. holdout 수치는 정보 제공용으로만 1회 계산하고 선택에 쓰지 않는다.
보고 수치: C 기준 값만 대표로 쓰고, M·H·Z, 8천만 계약 단위(1 MNQ = 7,600만), S&P 시대(밤 프리미엄 증거 없음, 참고) 를 함께 적는다.
