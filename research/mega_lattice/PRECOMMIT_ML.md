## 4. 확률별 분할 매매 (변형 = 시험 수 N)
- V1 (주안): 반-켈리 사다리. L* = 0.5·μ_t/σ²_t (σ² = 21일 반감 EWMA 일간 분산 × 21), [0, 3]으로 자르고 0.5 단위. 주 1회(주 첫 거래일) 결정, |L* − L| ≥ 0.75일 때만 바꿈. L≤1: QQQ L; 1<L≤2: QLD(L−1)+QQQ(2−L); 2<L≤3: TQQQ(L−2)+QLD(3−L).
- V2: 3단 확률 분할. P_t = 교차 적합 로지스틱(up ~ S). P ≥ p̄+0.05 → L 3, P ≤ p̄−0.05 → 0, 그 사이 1.5. 주 1회.
- B0 (대조, 정보 없음): V1에서 μ_t = 학습 평균 상수 (= 변동성 맞춤 사다리). 격자의 기여 = V1 − B0.
- 시험 수 N = 3 (V1, V2, B0). 견고성 이웃(κ 500/8000)은 보고만, 선택 안 함.
