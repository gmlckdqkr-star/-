## 0. 왜 MX1·BT1과 다른가 (진단 → 설계)
1. **목적함수 = v1을 직접 이기기.** 단독 규칙(3배/현금)이 아니라 v1의 실제 상태(목표 배수 B∈{0,1,3}, 2일 지연) 위에 덧씌우는 규칙이다. 점수는 v1 대비 로그 성장 차이(시간 평균, 거래 비용 포함)다. 그래서 "3배 비중이 크면 점수가 높다"는 BT1의 결함이 없다. v1이 이미 한 일은 점수가 0이다.
2. **평가 단위 = 탐색 절차 자체.** 해마다(1966~2014) 그 해 이전 자료로만 수백억 개 중 상위 규칙을 다시 고르고, 다음 1년에만 적용한다(전진 검증). 이렇게 이어 붙인 49년 흐름은 시도 수와 상관없이 표본 밖이다. 시도 수에 따른 선택 편향을 "추정"하는 대신 구조적으로 없앤다. MX1·BT1은 확인 구간을 한 번(15년)만 썼다.
3. **정보 = 넓은 교차 자산 + 비가격 85개 특성.** 거래 지수 가격 15, 미국 금리 곡선 26(3개월·1·2·5·10년, 연방기금), 신용 스프레드 5, VXO·TED 5, 업종·규모 상대강도·폭·분산 10, 채권·주식-채권 상관 4, 모멘텀 요인(UMD) 4, 환율 7(엔·파운드·프랑·캐나다·달러지수), 유가 3, 나스닥 종합 상대 2, 실업수당 청구 2, 해외 6개 시장 전역 3. 자료: 기존 저장소 패널 + FRED(H.15, H.10, TED, VXO, 유가, 달러지수, 나스닥 종합) + Ken French UMD + DOL 청구. 모두 공개·무료이고 같은 날 또는 발표 지연 반영(월별 자료 1개월 뒤, 청구 주 끝 + 6일).
4. **평균의 오류 금지 (사용자 11-12).** 선택 점수와 판정은 로그 성장(기하)과 실제 경로 하나의 연복리, 모의 경로는 중앙값만 쓴다. 산술 평균 수익률을 헤드라인으로 쓰지 않는다.

## 1. 자료 단위 (고정, code/build.py, data/mx2.npz sha 5724f86d978d7458)
- 창(window) 월 720개: S&P 1955-01~1985-12(v1을 S&P에 적용, MS1 real_spx_55_85 문맥) + NDX 1986-01~2014-12(MS1 real_ndx_86_14 문맥). 월말 e에 결정, e+2 종가 체결, e+3~다음 월말+2의 일별 수익.
- 일 수익: 수준 L의 포트폴리오 = (L/3)·(3r − 2rf − 2.45%/252), 쉬는 돈 이자 0(사용자 규칙). 덧씌움 차이 D = Σ 일별 [log(1+R(a(h))) − log(1+R(h))], h = v1 목표(3일 전 결정). 창 안 거래 차이와 창 경계 전환에 편도 0.3% 비용. 세금·계좌 브레이크는 선별 모형에서 빼고, 최종 확인은 MS1 엔진(세금·브레이크·청산세 포함)으로 정확히 다시 잰다.
- 행동 4개: CUT1(3배→1배), CUT0(→현금), ADD3(1배·현금→3배), ADD1(현금→1배).
- 원자 1,512개: 특성마다 확장창 백분위(결정 시점까지의 값만, 최소 25개월)가 q∈{.1..9}보다 크다/작다. 값이 없으면 거짓. 같은 비트 원자·켜짐 12개월 미만/708개월 초과(빈도만 봄) 제거.

## 2. 규칙 공간과 규모 (고정)
- R1 전수: 원자 1개, 2개(AND·OR), 3개(8가지 모양) 전부 = 약 46억 규칙 × 행동 4 = 약 184억 평가.

## 3. 전진 선택 절차 (주 절차, 고정)
- 절단 연도 Y = 1966..2014(49개). 학습 = 1955..Y−1의 연도별 D 합 S_y(S&P 시대 + 그 이전 NDX 연도 합동). 시험 = Y 한 해.
- 점수 = 학습 연도 S_y의 t(= ΣS / √(n·분산), 0인 해 포함 n = 학습 연수), 조건: 합 > 0, S_y ≠ 0인 해 ≥ 4.
- 선택 = t 상위 20개(같은 점수·같은 행동은 하나로). 시험 해의 덧씌움 = 20개 규칙의 수정 배수 평균(분수 배수).
- 보조(판정 아님): 상위 1개만; 점수 = 학습 합(ΣS) 상위 20.

## 4. 판정 (모두 통과해야 "v1을 넘음")
- **P1 정보(위약 대비)**: 같은 절차를 무작위 규칙 1억 개 부분집합(seed 777, 크기 2·3·4 = 10·40·50%)에서 진짜 1회 + 위약 100회. 위약 = D·비용을 원자에 대해 원형 이동(S&P 구간 24~348개월, NDX 구간 24~324개월, 시드 1..100 독립). 지표 = 49개 시험 해의 OOS 로그 성장 차이 합. p = (1 + #위약 ≥ 진짜)/101 ≤ 0.05. 그리고 전체(R1+R2) 주 절차의 OOS 합 > 0.
- **P2 실제 이력**: 전체 주 절차의 해마다 고른 덧씌움을 일별 v1 목표에 적용, MS1 엔진(F1 비용, 22% 세금, 청산세, 브레이크 0.85)으로 실제 NDX 1986~2014 연복리 > v1 같은 엔진 값, 그리고 S&P 1966~85 > v1. 쉬는 돈 이자 0 변형도 함께 보고.
- **P3 MS1 경로**: P1·P2 통과 시에만. 2015년 절단(1955~2014 전부 학습)으로 고른 20개를 고정해 MS1 dev250_path 중앙값 > v1. 경로에서 다시 계산할 수 없는 외부 특성은 날짜 덩어리로 같이 옮기고 그렇게 했다고 표기한다.
- 하나라도 탈락이면 "v1을 넘는 방법 없음"으로 쓰고 v1(15.2%) 그대로다. 숫자를 바꾸거나 기준을 낮추지 않는다.
