# MX2 결과: v1 위 덧씌움 규칙 383억 평가 + 해마다 전진 검증 (2026-11-12 09:05Z)

사전 등록: PRECOMMIT_MX2.md (sha bbff0560…), 자료 2014-12-31까지. 금지 파일·XV1·봉인 구간 사용 안 함. 판정은 기하 성장(로그)과 실제 경로 연복리만 썼다(평균의 오류 없음).

## 결론
- **v1을 넘지 못했다 (사전 기준 탈락).** 해마다 그 전 자료로만 383억 개 중 상위 20개를 골라 다음 해에 v1 위에 얹었다. 그 결과 실제 나스닥 1986~2014는 **v1 31.1% → 26.6% (−4.5%p/년)**, 최대낙폭은 −70% → −78%였다. 쉬는 돈 이자 0 기준으로는 30.5% → 26.3%였다.
- 정보가 아예 없지는 않았다. 같은 절차를 어긋나게 민 위약 100회보다는 덜 잃었다(p .0099). 하지만 v1이 이미 가진 정보보다 적어서, 얹을수록 손해다.
- v1 그대로 간다. 계획 수치 15.2%는 바뀌지 않는다.

## 왜 실패했나 (진단, R1 주 절차 분해)
- 고른 규칙의 학습 성적은 t 중앙 4.2, 연 +3.2%(로그)였다. 시험에서는 나스닥 연 −4.3%였다. 학습에서 보인 우위가 다음 해에 사라지고 뒤집혔다.
- 손실의 85%가 **v1이 빠진 때 다시 들어가는 규칙(ADD1 −0.70, ADD3 −0.35)**에서 나왔다. S&P 1955~85에서는 v1의 출구가 자주 헛신호였다. 그래서 "출구를 무시하라"를 배웠고, 그게 1987·2000~02 나스닥에서 크게 틀렸다. 출구를 더 일찍 하는 규칙(CUT)은 거의 0이었다.
- 정리하면, v1의 금리 경보 + 추세 출구를 넘는 시점 정보는 가격·금리·신용·변동성·업종·환율·유가·청구·해외 85개 특성의 1~4개 조합 안에 없다. 표본 밖에서 고르는 순간 손해가 된다. MX1(단독 규칙, 1회 확인)과 같은 답을 다른 방법(덧씌움, 49번 전진 선택)으로 확인했다.

## 검증
- C 커널과 numpy 대조: 최대 차이 6e-8. 선별 모형 v1 기준값은 MS1 엔진 31.08%를 재현했다.
- 선별 모형(세금·브레이크 없음)은 ADD 손실을 엔진보다 크게 본다(한 규칙 −19.9% vs 엔진 −7.3%). 그래서 판정은 엔진 행으로만 했다.
- 위약 100회는 같은 규칙 1억 개, D·비용을 S&P·NDX 구간별로 원형 이동(시드 20261112).
- 평가 수: R1 18,408,047,616 + R2 19,920,726,316 = **38,328,773,932** (+ 위약 399억, 부분집합 4억). 유효 독립 수는 훨씬 작다.
