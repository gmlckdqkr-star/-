# AT2 사전 등록: v1 금리 경보가 다른 나라에서도 통하나 (6개국, 2026-11-12, 스레드 "Opus로 v1 넘는 방법 따로 찾기")

계산 전에 고정. Q1(일본 1개국, 스레드 "처음부터 새로 매매법 연구하기", 결과 "통하지 않음")을 다른 시장으로 넓힌다. 일본은 다시 돌리지 않고 Q1 결과를 그대로 인용만 한다. XV1 파일·등록과 무관. 자료는 2014-12-31에서 자른 뒤에만 저장, 2015년 이후 행은 계산·출력하지 않는다. 금지 파일 열지 않음.

## 1. 질문
v1(std.s085: 3배 목표, 20일 변동성 상한, 금리 경보(inv: 378행 안에 10년물 < 3개월물, shock6m: 10년물 126행 +1.0%p)가 켜졌을 때만 200일 추세 이탈을 따름, av23s 0.85 브레이크)의 금리 경보가 미국 밖에서도 타이밍 정보를 갖는가. 경로 대표값 15.2%(경보를 거의 못 씀)와 붙인 값 26.4%(경보가 역사대로 맞음) 중 어디를 믿을지에 대한 증거를 늘린다. Q1이 "독일·영국 일별 지수가 무료로 없음"이라 1개국만 했으나, 2026-11-12 Yahoo 일별 지수(요청 끝 2014-12-31)를 받을 수 있음을 확인했다.

## 2. 시장·자료 (고정)
- 영국 FTSE 100(1984-), 캐나다 S&P/TSX(1979-06-), 호주 All Ordinaries(1984-08-), 독일 DAX(1987-12-, 배당 포함 지수), 프랑스 CAC 40(1990-03-), 스위스 SMI(1990-11-). Yahoo 일별 종가, r = 종가/전일 − 1.
- 금리: FRED OECD 월별 3개월 금리(IR3TIB01xxM156N)·10년 국채(IRLTLT01xxM156N). 달 m의 값은 m+1월 첫 지수 행부터 사용(Q1과 같은 관례). rf = y3m/100/252. 신용 스프레드·VIX 없음(v1은 읽지 않음).
- 채점 구간: 지수 첫 행 + 300행(엔진 예열) ~ 2014 마지막 행, 연속 계좌 1개. 378행 경보 되돌아보기는 실제 금리로 덮여야 함(코드에서 확인).

## 3. 계좌 (v1 그대로)
std.engine(beng.F1: 지연 2, 비용 0.003, 세금 22%·청산세, 3배 펀드 3r − 2rf − 2.45%), cspr = 10.0(쉬는 돈 이자 0). 현지 통화 기준, 가상의 3배 지수 펀드(현지 3개월 금리로 조달). 시험 대상은 경보의 정보이지 거래 가능한 상품이 아니다.

## 4. 실행
- A: 실제 경보. 위약(placebo): 경보 표 전체를 계좌 행 안에서 시장과 어긋나게 원형으로 s = 504 + 63j 행 밀기(j = 0,1,…, s ≤ N − 504). ALWAYS(inv 항상 켬 = 추세 이탈 항상 따름), NEVER(경보 전부 끔), 1배 보유.

## 5. 판정 (유일한 결정)
- 시장별: S = CAGR(A) − 위약 중앙값, p = (1 + #위약 ≥ A)/(1 + #위약). "통함": S ≥ +3%p 그리고 p ≤ 0.10. "안 통함": S ≤ 0 또는 p ≥ 0.50. 나머지 "불분명".
- 합동(6개국): 평균 S와 Fisher 결합 p. "통함": 평균 S ≥ +2%p 그리고 Fisher p ≤ 0.10. "안 통함": 평균 S ≤ 0 또는 Fisher p ≥ 0.50. 나머지 "불분명". 참고 줄로 일본(Q1: S −0.6, p 0.76)을 넣은 7개국 값도 보고.
- 사용자에게 읽는 법(고정): "통함"이어도 계획 수치는 15.2%를 유지하되, 15.2%가 보수 쪽이라는 근거가 생긴다. "안 통함"이면 v1의 미국 밖 우위는 추세·변동성 부분뿐이고 15.2% 근처가 맞다는 근거가 강해진다. 방법을 바꾸지 않는다(선택 없음).
