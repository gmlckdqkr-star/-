# VXR1 사전 등록: VIX 선물 롤 프리미엄 보조 흐름을 v1 옆에 두기 (2026-11-12, 스레드 "Opus로 v1 넘는 방법 따로 찾기")

계산 전에 고정한다. 이 파일의 sha256을 PRECOMMIT_VXR1.sha256에 남기고, 이후 바꾸면 ADDENDUM으로만 바꾼다.
XV1(스레드 "처음부터 새로 매매법 연구하기")의 파일·등록·봉인과 무관하다. 2015년 이후 행은 계산·출력·저장하지 않는다(자료는 2014-12-31에서 자른다).
금지 파일 목록(memory forbidden-files)은 열지 않는다.

## 0. 왜 이 축인가
- 등록부: T02(VIX를 나스닥 시점 신호로)는 닫힘. "변동성 선물 매도"는 X46에서 심사로 제외, **시험 0건**(같은 계열 L02/T32로 분류). L02(VP1)는 블랙숄즈 재구성 지수옵션 매도였다.
- VIX 선물 기간구조 롤(콘탱고에서 만기로 수렴하며 생기는 손실)은 지수옵션 VRP와 다른 수익원이며, 실제 Cboe CFE VX 정산가(2004-03~2014)는 이 프로젝트에서 한 번도 적재·측정되지 않았다.
- 사전 기대(추론): 단독 흐름은 평온기 수익이 크고 충격일 손실이 크다. v1의 3배 구간과 같은 국면에 돈을 벌어 상관이 높을 수 있다(VP1 실패 이유와 같은 위험). 통과 확률은 낮게 본다(≤20%).

## 1. 상품 모형 SVX (현물 ETF로 구현: 키움 해외주식, SVIX −1배·SVXY −0.5배형, PTP 주의)
- CM1 = 30일 고정 만기 VIX 선물 지수(S&P VIX 단기 선물 지수와 같은 생각): 매일 M1·M2 두 근월물을 만기까지 남은 달력일로 선형 보간해 잔존 30일이 되게 비중 w1=(T2−30)/(T2−T1) (0~1로 자름), w2=1−w1. 비중은 t−1 종가에 정하고 t의 정산가 변화로 수익 r_CM1,t = Σ w_i,t−1 (F_i,t/F_i,t−1 − 1). 만기일 = 각 계약 파일의 마지막 거래일. 정산가 0이면 종가, 둘 다 없으면 그 계약 그날 제외(그날 다른 계약만으로 정규화). 2007-03-26 이전 가격은 10배 표기이므로 비율 계산이라 그대로 둔다(수준이 필요할 때만 /10).
- SVX 일수익 = −r_CM1 + rf − (0.95% + 0.5% 추적손실)/252. 22% 양도세(계좌 엔진, 해마다 실현 순익·250만원 공제·청산세), 편도 0.3%.
- ACTUAL 구간 = CM1이 처음 계산되는 날 ~ 2014-12-31. 그 전은 SYNTH(재구성, ACTUAL과 섞어 부르지 않음):
  - V = VIX 종가(1990~), 그 전은 VP1과 같은 대용(m × max(rv21, rv63) × 100, SPX 실현변동성, m은 vpdata.vix_rv_ratio()).
  - r̂ = β·Δln V_t + a + b·z_{t−1}, z = ln(V / 252일 후행 평균 V).
  - β = ACTUAL 구간 sd(r_CM1)/sd(Δln V) (상관 1로 본 보수값: 충격 손실 크게). a, b = (r_CM1 − β Δln V)를 [1, z]에 회귀(OLS, ACTUAL 구간).
  - 보수 깎기: SYNTH 구간의 프리미엄(−평균 r̂)을 25% 줄인다(a에 0.25×|ACTUAL 평균 r_CM1| 더함). 스트레스에서 50%.
  - 검증 보고: ACTUAL 구간에서 재구성 r̂ 대 실제 r_CM1의 일·월 상관, 평균, 최대 일 상승.

## 2. 계좌 구조와 후보 (N = 6, 전부 보고)
- 계좌 = v1 슬리브 (1−s) + SVX 슬리브 s. 분기마다(63거래일) 두 슬리브를 목표 비중으로 재조정(세금·비용 엔진 그대로).
- SVX 슬리브는 관문이 켜지면 SVX 100%, 꺼지면 현금(이자 0). 관문은 종가 t에 계산, t+2부터 효력(MS1 지연 2일).
- 관문(경로 위에서 다시 계산, 붙이지 않음):
  - G0 항상 보유.
  - G1 변동성 프리미엄 양수: V_t > 100·√252·sd(SPX 일수익, 최근 10일).
  - G2 낮은 변동성 국면: V_t < 252일 후행 평균 V.
- s ∈ {0.10, 0.20}. 후보 = {G0, G1, G2} × {10%, 20%}.
- 비교 기준: 같은 엔진의 v1 단독(현금 이자 0). 같은 경로끼리 짝 차이 d.

## 3. 측정 기준
- MS1 5기준(user_port_up 다계좌 엔진, 현금 0): dev250_path(대표), dev250_glued, real_ndx_86_14, real_spx_55_85, real_spx_70_85(SPX 시대는 전부 SYNTH 대용이라 참고만).
- 추가 ACTUAL 창: real_ndx_86_14 한 경로의 곡선에서 CM1 첫날 ~ 2014-12-31 구간 연복리(v1 단독 vs 후보). 이 창만 재구성 없는 증거다.

## 4. 통과 조건 (후보마다, 모두 충족해야 통과)
- P1 dev250_path 중앙 d ≥ +0.5%p 이고 이긴 비율 ≥ 55%.
- P2 real_ndx_86_14 d ≥ +0.5%p.
- P3 ACTUAL 창 d ≥ +0.5%p.
- P4 dev250_path −80% 도달 비율이 v1보다 5%p 넘게 나빠지지 않음.
- P5 스트레스 4개 각각에서 dev250_path d > 0 그리고 ACTUAL 창 d > 0: (a) 비용 2배 + 추적손실 +1%/년, (b) SYNTH 프리미엄 50% 깎기, (c) 관문 지연 3일, (d) 상품 내 rf 수입 0.
- 충격 보고(통과 조건 아님, 반드시 표기): ≤2014 CM1 최대 일 상승 ×1.5 하루와, 가정 사건 "CM1 하루 +100%"(−1배 상품 전액 손실)에서 계좌 손실.
- 다중검정: N=6. 통과가 1개뿐이고 이웃(같은 관문 다른 s)이 실패하면 "우연 가능" 표기.
- 통과해도 v1 교체 제안이 아니라 사용자 결정용 후보로만 보고한다(PTP 원천징수 위험, 실거래 상품 차이).
