# 연구 실험실 (lab) — 시제품 v0

전략 아이디어를 **짧은 명세 파일(YAML 10~20줄)** 로 쓰면, LLM 없이 로컬에서
백테스트 → 비용·세금·지연 반영 → 재표본 → 봉인 구간 판정 → 기록(원장)까지 하고 **결과를 한 줄**로 돌려줍니다.
Claude는 명세를 쓰고 한 줄만 읽으면 되므로, 매 연구마다 코드를 새로 쓰고 긴 로그를 읽는 토큰이 빠집니다.

## 실행
```
python3 -m lab run specs/trend_tqqq_200.yaml specs/voltarget_qld.yaml
python3 -m lab ledger
python3 tests/test_parity.py      # 기존 beat_qld 엔진과 결과 일치 확인
```
- 가격 자료: 환경변수 `LAB_PANEL` (기본 `/mnt/project-files/research/data/panel_f32.npz.xz`)
- 원장·상세 결과: `LAB_HOME` (기본 `lab/var/`, 저장소에 올리지 않음)

## 규칙 (코드로 강제)
- 신호는 결정일 종가까지의 자료만 사용, 체결은 1봉 지연(`delay: 2` = beat_qld 엔진과 같은 정의).
- 비용 편도 0.30%(수수료 0.25% + 스프레드 0.05%), 해외 양도세 22%(연 단위, 청산 시 과세).
- 레버리지 ETF 상장 전 구간은 기초지수 × 배율 합성(SYN), 상장일부터 실제 ETF.
- 신호의 `price(TQQQ)` 같은 상품 이름은 **기초지수**를 뜻함(기존 연구 엔진과 같음).
- 2015년 이후(봉인 구간) 수치는 출력·저장하지 않고 PASS / REJECT / BUDGET만 돌려줌.
  개발 구간 관문을 통과한 명세만, 계열당 정해진 횟수(기본 5회)까지 봉인 구간을 봄.
- 같은 명세(해시 같음)는 다시 계산하지 않고 원장 값을 돌려줌. 계열별 시험 수 N을 셈.
