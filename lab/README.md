# 연구 실험실 (lab) — v2

전략 아이디어를 **짧은 명세 파일(YAML 10~20줄)** 로 쓰면, LLM 없이 로컬에서
개발 구간 요약(≤2014) → **MS1·G1 자동 보고** → 프로젝트 기준 판정 코드(blackbox2 + d6q)로 판정 → 원장 기록까지 하고
**결과를 한 줄**로 돌려줍니다. 대상: 미국 상장 ETF 상품, 국내 지수 ETF(`account: kr_etf`), 미국 개별 종목(`universe: sp500`).

**보고에 인용할 숫자**: ETF 명세는 MS1 대표값(`MS1 경로 x%`, 하한과 함께), 개별주 명세는 `세후 보수 x%`(1986~2014, 상폐 분류 규칙: 실패형 −50%·인수형 0; 게이트·신호 준비일이 늦으면
`(게이트 1986-07~)`·`(신호 2003-06~)`처럼 그날부터)와 `MS1(수익 흐름 재표본) 경로 x%`. `개발 인과성 위반` 명세의 숫자는 인용하지 않음. 개발 요약(`개발(...) 세후 x%`)·빠른 선별 숫자만 따로 인용하지 않음(개발 선별, 기준 아님).
MS1이 `해당 없음`인 명세는 그 이유를 같이 적음.

  (`이름 hash lg/QLD/QQQM 개발12y MS1경로·G1 판정·미달관문`; 판정 단계 없으면 MS1 경로 순, MS1 없는 명세는 그 뒤 개발 12년
  배수 순). G1 칸 = `CLOSE`/`HOLD`/`BUILD`/`60%-CANDIDATE`, 늘 안(밖)이면 `상시·샤프닫음|샤프통과`(늘 밖 `상시현금·..`: 비용 후·세전 샤프 vs 1.1), 개별주 게이트가
  G1 틀 밖이면 `게이트 해당없음`. **개발 인과성 위반 명세는 숫자와 관계없이 맨 뒤**, 판정 칸에 `인과성위반`. 개별주 명세는 아래
  `-- 개별주` 블록에 따로(세후 보수 순 상위 5, `세후보수 x%[(시작~)][ 종목0] MS1 y%[·G1 게이트 판정] Sharpe G1 통과/미달`;
  86~14 창이 늦게 시작하면 `(03-05~)`처럼 시작 연월).
- ETF·국내 ETF·개별주 명세를 한 폴더에 섞어도 한 번에 돎(`lab run specs/examples --bar none`). MS1 작업자는 배치당 1개.
- 한 줄이 400바이트를 넘으면 개발·판정·MS1 부분을 같은 숫자의 짧은 꼴로 바꿈, 그래도 넘으면 머리의 명세 이름·계열을 20바이트로
  줄이고, 다음엔 끝의 실행 시간을 빼고(판정 부분은 남김), 그래도 넘으면 끝을 자름. 전체는 `LAB_HOME/out/batch_<UTC>.json`. 오류도 한 줄(줄바꿈은 ` / `).
- 머리 `[이름] 계열=f N=n`: 같은 해시를 다른 `family`로 다시 돌리면 시험은 **처음 센 계열에 남고** 그 계열과 N으로 보고·G1 보정
  (`(중복: 원장 계열 X, 명세 Y)`). 명세에 `family`·`known`이 없으면 `(family·known 없음)`(계열은 `unset`에 섞임 — 꼭 쓸 것).
- 개발 요약에도 **인과성 시험**(실제 ≤2014 자료를 무작위 12곳 + 주·월·분기 경계 24곳에서 잘라 비중 비교, plugin은 무작위 300곳)이 붙음.
  위반이면 `개발 인과성 위반`, 개발선별 탈락, **MS1·G1은 계산하지 않음**(`MS1: 계산 안 함 (개발 인과성 위반)`: 경로에서도 같은
  미래 읽기라 숫자가 새어 나옴). 자른 자료는 짧은 것부터, 전체 자료는 마지막에 계산.
- 개발 구간 표시 `개발(2001~2014, 신호 2002-05~)`: 명세가 읽는 지표(sma·ret·vol … 식 안의 호출 하나하나) 중 마지막으로 값이 생긴
  날이 개발 시작보다 늦으면 그 날(그 전엔 그 조건이 거짓으로 읽힘). 0으로 채우는 invvol·rp는 못 봄.
- 개발 요약 엔진: `rebalance`가 daily가 아니면 표본일(기간 첫 거래일)마다 목표 비중으로 **되돌려 거래**(고정 비중도 표류하지 않음).
  판정 쪽 중개는 자체 규칙(6% 표류 띠)으로 재조정하므로 두 쪽의 재조정 방식은 다름. daily 명세는 예전과 같음(beat_qld 일치).
- 가격 자료: `LAB_PANEL` (기본 `/mnt/project-files/research/data/panel_f32.npz.xz`). 행 날짜 = 시세가 난 곳의 날짜(런던 시각으로
  읽음: FX `KRW_X`는 런던 00:00 봉이라 여름엔 23:00 UTC 표시 — 예전엔 하루 앞 날짜로 들어가 그날 값에 다음 날 움직임이 섞였음).
  미국·국내 키는 날짜 그대로. 주말 날짜 행 없음(시험).
- 원장·상세 결과: `LAB_HOME` (기본 `lab/var/`, 저장소에 올리지 않음). 상세 JSON은 `LAB_HOME/out/<hash>_<mode>.json`.

## 판정 단계 (`--bar`)
- `quick` — **빠른 선별 (기준 아님)**: 10년 b63 1000만원 1개 실행, 400경로(기준 실행 2000경로의 앞 400경로, 같은 씨앗),
  자체 원천·KRWX·src_end 2014-12-31. Q1·Q2·Q3·R1·R2·R3·W5(7년 배수) 중 미달 이름을 보여줌. 판정 아님.
- `full` — 프로젝트 기준(APPLY-Q60 = A17 Q + A50 G60-W + A49 G-MKT)을 lab이 계산할 수 있는 만큼 적용.
  필요한 4판(자체/공통 × KRWX/DEXKOUS) × Q 실행 10개 + G60-W + G-MKT (a)(b)(c) + 계산 가능한 전제 관문.
  출력 이름:
  - `REJECT` — Q/R 관문 또는 전제(D2, A7, 인과성, 판 불가) 실패 = APPLY-Q 탈락(따라서 APPLY-Q60도 탈락).
  - `REJECT (lab 판정, 미확정)` — Q 수준 실패가 기준 담당 미확인 lab 이식(G4_dev)뿐.
  - `Q60 미달 (Q 미판정)` — G60-W / G-MKT만 실패: APPLY-Q60 미달, APPLY-Q 여부는 lab이 판정 안 함.
  - `PENDING (통합 담당 대기)` — lab이 계산하는 관문은 모두 통과.
  **lab은 APPLY-Q / APPLY-Q60을 출력하지 않음**: PBO, 블라인드 A, DSR(시험 수 N 미정), G7 스트레스(공식 창이 2015+),
  검증 Q, 블라인드 B·D, 파이프라인 관문(recon_crisis_mdd, deep_dd80, deep_mdd_vs_QQQ, deep_underwater_vs_QQQ)은 통합 담당 몫.
  확정 관문이 실패하면 남은 판은 건너뜀(`--all-versions`로 끔). 실제 경로의 lab 이식/해석(G4_dev, G-MKT (c))
  실패로는 멈추지 않음. 판 하나 약 4분(4 작업자) — 동시에 한 개만 실행.
  G-MKT (c) 구간 = 사상 최고점 기준(Generator.bear) ∪ 국지 고점(20% 하락/20% 반등) ∪ 국지 고점→회복 전 최저점의
  합집합(엄격 쪽, lab 해석). 인과성 = 실제 경로(고정 3 + 무작위 40 + 주·월·분기 경계 24 절단) + 부트스트랩 2경로(무작위 40 + 경계 24씩;
plugin은 무작위 300), quick에서도 부트스트랩 2경로.
- `none` — 개발 요약만.
- 판정 가능한 상품: QQQ(→QQQM), QLD, TQQQ, SSO, UPRO, TMF, SPY, TLT, IEF. 그 밖의 상품(SOXL, GLD, SHY …)은
  공통 원천 대용이 없어 `REJECT (version impossible)`.
- 판정 경로의 규칙: 경로마다 명세를 다시 계산(합성 가격), 실제 과거 시세 읽기 차단, 비중은 합 ≤0.88·Σ배율×비중 ≤2.64로 축소,
  워밍업 300일(더 긴 되돌아보기는 처음에 비어 있음), 합성 경로의 month()/weekday()는 의미 없음,
  명세의 `delay`는 판정에 안 씀(중개 지연 0: 종가 결정 → 다음날 시가 체결).
- 명세 검사: `delay`는 정수 ≥2만 허용(`delay: 2` = 종가 t에 결정 → 종가 t+2에 거래 → t+3일 수익부터 받음; 1이면 다음 종가 t+1,
  0이면 결정 종가 그 자체에 거래), `cost`는 0.003 미만이면 0.003으로 올림
  (판정 쪽은 비교 기준 QQQM/QLD 보유에도 같은 비용이 들어감).
- **계좌 `account:`** — 기본 `us`(미국 상장 ETF: 편도 0.30%, 연간 순이익 22%). `account: kr_etf` = 국내 상장
  해외지수·레버리지 ETF: 편도 13bp(명세 `cost`로 올리기만 가능), **매도할 때마다 그 이익의 15.4% 원천징수, 손실 상계 없음**
  (보수적. 과표기준가 규칙·ISA 비과세는 반영 안 함), 수익 계열은 같은 상품 계열 그대로(원화 환율·국내 ETF 보수/추적오차 미반영).
  판정 경로는 미국 증권사 기준이라 kr_etf는 개발 요약만 계산하고 기준은 **판정 불가 (KR 계좌)** 로 표시.
  예시 `specs/examples/kr_qld_trend.yaml`.
- **국내 지수 ETF 상품 (kr_etf 계좌 전용)** — `KR200`(069500 KODEX 200), `KRLEV`(122630 KODEX 레버리지),
  `KRINV`(114800 KODEX 인버스), `KRSEMI`(091160 KODEX 반도체). 자기 가격 계열 그대로(상장 전 합성 없음), 패널의

## 미국 개별 종목 (universe: sp500)
S&P 500 편입 종목 안에서 고르는 횡단면 전략. 명세 + `lab run` 한 번 = 개발 요약 + MS1(수익 흐름 재표본) + G1
(판정은 `판정 불가 (개별주)`: 판정 경로는 ETF 상품만 다룸). 1970~2014, 개발 구간만.
```yaml
name: stk_mom12_1_top20
family: stk_mom
universe: sp500
stock:
  rebalance: month          # month | quarter | week — 기간 첫 거래일 종가에 결정
  score: "ret(231, 21)"     # 종목별 식, 큰 값부터 고름 (12-1 모멘텀 = P[t-21]/P[t-252]-1, 창 252행)
  filter: "age() >= 252"    # 선택: 종목별 참/거짓 식
  top: 20                   # 또는 top_pct: 0.1
  weight: equal             # equal | invvol(63) | score
  max_weight: 0.10          # 선택: 종목당 상한, 넘는 몫은 CASH
  exposure: up              # 선택: 신호 이름 또는 ETF DSL 식 (참=1, 숫자는 0..1)
  else: {CASH: 1.0}         # 노출 안 된 몫 (CASH 또는 미국 ETF 상품), 기본 CASH
  exposure_every: daily     # daily(기본, 매 종가) | rebalance(결정일만)
signals: {up: "price(_NDX) > sma(_NDX, 200)"}   # 선택, 기존 ETF DSL (ETF 패널 + _SP500EW, 2014-12-31에서 자름)
```
국면에 따라 종목 고르기(STOCK_VERSION 5, 예시 `stk_regime_switch`):
```yaml
signals: {up: "price(_SP500EW) > sma(_SP500EW, 200)"}
stock: {score: "up * rank(ret(231, 21)) + (1 - up) * rank(-vol(252))", top: 20}
```

- **score·filter 안의 신호 이름** (STOCK_VERSION 5): `signals:`에 정의한 이름을 score·filter에 그냥 쓰면 **결정일 t 종가의
  그 신호 값** 하나(모든 종목에 같음; 참 = 1.0, 거짓 = 0.0, 숫자는 그대로). 신호가 t에 **정보 있음** = 값이 유한하고, 그 신호와
  그것이 읽는 신호 안의 지표 호출(`sma`·`ret`·`vol` 등, `dsl.valid_from`과 같은 목록)이 모두 t에 값이 있음(DSL에서 값 없는
  `sma`와의 비교는 거짓이라 참/거짓만으로는 빠진 값을 모름). **정보 없는 결정일은 자격 종목 0 → 주식 몫은 현금**(노출·else
  몫은 그대로) — 빠진 값을 0으로 읽지 않음(`not up`이 전부 통과되지 않음). 첫 정보 결정일 = `signal_from`(예 `sma(_SP500EW,
  200)` → 1970-11-02): 늦으면 1986~2014 창과 MS1 흐름이 그날(+지연 2)부터, 줄에 `(신호 2003-06~)`, 1971 줄엔 `(신호 2003~)`(가장 짧은 꼴도 `71~14 x%(신호03~)`)
  (게이트 준비일과 같은 방식). 신호 이름이 종목별 함수(`rank` `age` ..)나 거부 입력 이름(`close` `dvol` ..)이면 거부. 창 인자는
  여전히 식에 쓴 숫자만(`ret(up)` 거부), 종목별 창 ≤260행 그대로(신호는 지수 계열이라 종목별 창을 못 만듦), `dvol`은 신호
  안에서도 거부. 산술은 그대로라 `0 × NaN = NaN`: 안 쓰는 쪽 값이 없는 종목도 점수가 없음(필요하면 `filter`로 자격을 맞춤).
  `up * rank(..)`만 쓰면 down 국면엔 모든 종목 점수가 0 = 전부 동점 → 아래 **상위 K 동점 규칙**대로 그 국면엔 자격 종목 전부를
  똑같이 보유(줄에 `동점분할 n/m회`). 신호가 한 번도 정보 없으면(예 `sma(TLT, 5000)`) 종목 0이고 줄이 그 호출을 적음
  (`종목 0 (score·filter 신호가 2014년까지 한 번도 정보 없음: sma(TLT, 5000) 값 없음)`).
  신호는 순위만 바꾸는 것이라 타이밍 게이트가 아님(늘 투자) → G1 = Sharpe 줄.
- **`_SP500EW`** (시점별 동일가중 S&P 500 편입 종목 지수, 개별주 패널에서 만듦): t일 수익 = t−1에 편입이었고 t−1·t 둘 다
  가격이 있는 종목의 수정종가 수익 평균(496~502종목; stale·거래정지·dvol 안 읽음, 편입 종목만 읽어 편입 전 가격 없음, 상폐
  수익은 안 넣음 — t에 가격이 다시 나올지 모름), 수준 1.0 = 1970-01-02(첫 PIT 편입일), 그 전 NaN. t 값은 t−1·t 행만 읽음(인과,
  시험: t* 뒤를 바꾼 패널에서 t*까지 같음). ETF DSL에서 `_NDX`처럼 씀(`price` `sma` `ret` `vol` `dd` `zscore` ..; 창 규칙도 ETF DSL —
  지수라 260행 상한 없음) → lab `_NDX`(1985-10~)가 없는 1971~1985 국면도 잼(S&P 500 일간 수익과 상관 0.965). **ETF 명세도
  읽을 수 있음**(개발 요약만, ETF 틀에서 1985-10부터 = 다른 패널 계열과 같음): 판정 경로엔 없어 `REJECT (version impossible)`,
  MS1 `해당 없음 (읽는 계열 _SP500EW: ..)`. 개별주 `exposure` 게이트가 읽으면 `G1 게이트 해당 없음 (읽는 계열 _SP500EW: ..)`(G1
  틀엔 NDX·S&P만; 게이트 명세엔 노출이 읽는 신호만 넣으므로 score만 읽는 `_SP500EW` 신호는 NDX 게이트의 G1을 막지 않음).
- **종목별 함수** (결정일 행에서만, 창은 결정일 종가에서 끝남, 창 ≤260행): `ret(n[, skip])` skip일 전에 끝나는 n일 총수익,
  `vol(n)` 일간 수익 표준편차, `sma_ratio(n)` 가격/n일 평균, `high_dist(n)` 가격/n일 최고 −1, `age()` 첫 편입일 뒤 거래일 수,
  `beta(n)` 동일가중 편입종목 수익 대비 베타, `rank(x)` 0..1 백분위, `csz(x)` z점수 (rank·csz는 그날 편입·가격 있는 종목 안에서),
  `abs min max log`, `+ - * /`, 비교, `and or not`. 창 인자는 숫자 상수만. 모르는 함수·이름은 오류. 가격 없는 날은 직전
  가격(수익 0)으로 잇고, 창은 창 바닥(첫 편입일; 1970-01-02 편입 종목은 첫 가격) 뒤에서 시작해야 값이 생김.
- **편입 자격**(결정일 t 종가): t에 편입, t에 가격 있음, filter 참, score 값 있음(invvol이면 vol도). 거래 없는 날 표시·거래정지
  구간은 결정에 안 씀(META 거래정지 6건은 편출 때문에 기록된 것인데 모두 편입 기간과 2~695행 겹침 → 결정에 쓰면 미래 편출과 엮임). 보유 종목이 지수에서 빠지면 **다음
  결정일에 매도**(미리 팔지 않음).
- **상위 K 동점 규칙** (STOCK_VERSION 6): 점수 상위 K개. K번째 점수와 같은 종목이 남은 자리보다 많으면 **그 동점 종목들이
  남은 자리를 똑같이 나눔**(종목마다 자리 수/동점 수만큼의 비중 = 동점 순서를 무작위로 했을 때의 기대 장부; equal·score 비중은
  정확히, invvol은 나눈 몫에 1/vol 비중). 6 전에는 패널 열 순서로 끊었는데 그 순서는 **출처의 마지막 기호의 알파벳 순**(2014년
  뒤 개명 포함, 시점 사실 아님)이라 동점이 많은 명세(`up * rank(..)`의 down 국면, 참/거짓 점수, 52주 고점 `high_dist` = 0)는
  기호 순으로 종목을 골랐음 → 열 순서를 바꿔도 장부·CAGR이 같음을 시험함. 전부 동점이면 자격 종목 전부 보유. 줄에
  `동점분할 n/m회`(1986 창에 걸린 결정 m번 중 n번, 있을 때만; 상세 JSON `ties`), 무작위 바구니는 같은 종목 수·같은 합계 비중.
  예시 중 `stk_quality_proxy`(순위 세 개의 합)가 몇 번 경계 동점이 있음.
- **수익·체결**: 수정종가 종가-종가. 거래정지(META `exit_gaps`, 예 EHC −97%)는 가격을 이어 **재개일에 변화 전체**를 씀.
  가격이 끝난 뒤(2014-12-31 전) 다음 날 **상폐 수익** 한 번, 그 뒤 0. **상폐 분류 규칙(대표)**: 마지막 가격까지 250거래일(이력이
  짧으면 있는 만큼, 20일 이상) 수익이 −30% 미만이면 **실패형 −50%**(Shumway NYSE −30%와 Nasdaq −55% 사이, 보수적), 아니면
  **인수형 0**(인수는 대략 마지막 가격에 지급). 분류는 그 종목의 마지막 가격까지의 가격만 씀(끝나는 시점에 알 수 있음).
  엔진은 ETF와 같은 `engine.run`(지연 2 = 종가 t 결정 → 종가 t+2 거래 → t+3일 수익부터, 편도 0.30%, 연간 순실현이익 22%, 마지막
  청산 과세, 현금 T-bill)에 개별주용 규칙 하나만 더함: **거래정지 구간·시계열 안 가격 없는 날은 그 종목 거래 불가**(정지 중엔
  팔 수 없어 재개일에 다시 시도, 정지 중 고른 종목은 재개 후에야 삼, 가격 없는 종목은 못 삼). 계산은 같은 규칙의 벡터 빠른
  경로(engine.run과 1e-13 일치 시험).
- **한 줄 결과 읽는 법** (모두 ≤2014, 세후 = 22% 과세 뒤 CAGR):
  `개별주 S&P500(시점편입·상폐포함) 1986~2014 세후 보수 x% (기본 y%·일괄-30% w%·극단 z%) 낙폭 m% [동점분할 k/j회] 평균 n종목 회전 t x | 동일가중 a% · NDX보유 b% |
  1971~2014 c% | 무작위 바구니 상위 p% (95%선·99%선 통과/미달) | Sharpe s (G1 1.1 통과/미달) | 기준: 판정 불가 (개별주) |
  MS1(수익 흐름 재표본) 경로 e% (하한 f%, s0.85 16.2·1x 11.6) dd80 g% s0.85대비 ±d%p [| G1 게이트 ...]`
  400바이트를 넘으면 같은 숫자의 짧은 꼴로 바꿈: 개발 부분은 `평균 n종목 회전`·95%선을 빼고, 더 넘으면
  `개별주PIT·상폐포함 86~14 세후보수 x%(기본 y·일괄30 w·극단 z) 낙폭m% | EW a·NDX b | 71~14 c% | 무작위 상위p%(99%선 ..) | 샤프 s G1 1.1 ..`,
  MS1은 `MS1(수익 흐름 재표본) 경로 e% (s0.85 16.2·1x 11.6)` → `MS1흐름 경로 e%(s0.85 16.2·1x 11.6)`,
  G1 게이트는 `G1게이트 NDX적중/상시·SPX적중/상시 보정 N 판정` → `G1게이트 NDX·SPX 보정 N 판정`.
  - **보수 x% = 대표값**: 위 상폐 분류 규칙(실패형 −50%·인수형 0). 기본 y% = h=0(마지막 가격에 청산). 일괄-30% w% = 보유 중
    가격이 끝나면 모두 −30%(STOCK_VERSION 2까지의 대표 규칙; 인수 대상을 많이 드는 모멘텀 등을 깎음, 스트레스 행). 극단 z% = 기본 +
    보유 종목마다 해마다 6% 확률 −100% (씨앗 고정 20회 중앙값, 참고용). 낙폭·평균 종목 수(노출 안 된 날 0)·회전(연간
    매수+매도/평가액)은 보수 행. 상세 JSON `held_ends` = 1986~ 보수 장부가 끝까지 든 상폐 종목 수(실패형·인수형).
  - **게이트 준비일**(`gate_from`): 게이트(exposure와 그것이 읽는 신호; score만 읽는 신호는 빼고) 식 안의 지표가 모두 값을 가진 첫 결정일(예 `_NDX > SMA200`: lab `_NDX`가
    1985-10-01부터라 1986-07-16). 그 전엔 비교가 거짓 = 강제로 `else`(현금)라서 **1986~2014 대표 창은 그날(+체결 지연 2일)부터**
    시작하고 `1986~2014(게이트 1986-07~)`로 표시(TLT 게이트면 `2003~2014(게이트 2003-05~)`). 동일가중·NDX보유도 같은 시작.
  - 동일가중 a% = 매월 편입 종목 전부 동일가중(같은 엔진·비용·세금·상폐 분류 규칙). NDX보유 b% = lab QQQ 상품 1배 보유(1999년 전 _NDX 가격지수,
    배당 없음). 1971~2014 c% = 보수 행의 긴 구간(`else`가 ETF면 그 상품 자료 시작부터; 게이트 준비일이 늦으면 그 전은 현금이고
    `(게이트 1986~)` 표시).
  - **신호 준비일**(`signal_from`, 상세 JSON `signals`: 이름·읽는 신호·준비일·그 뒤 정보 없는 결정일 수 `gaps`): 위 score·filter
    신호 항목. 게이트 준비일과 같게 1986 창 시작·표시(`(신호 ..~)`), 둘 다 늦으면 더 늦은 쪽.
  - 종목을 한 번도 안 드는 명세(filter가 아무것도 안 맞음, 게이트가 늘 꺼짐, 단위 실수)는 `종목 0 (filter/게이트 확인): 현금(T-bill)만
    세후 x%`로 찍고 무작위 바구니·Sharpe는 계산 안 함(G1 미달); score·filter 신호가 한 번도 정보가 없어 종목 0이면 괄호가
    `(score·filter 신호가 2014년까지 한 번도 정보 없음: <호출> 값 없음)`. 초과수익 표준편차 1e-12 미만이면 Sharpe 없음(`-`).
  - `동점분할 n/m회`: 위 상위 K 동점 규칙이 1986 창 결정 m번 중 n번 쓰였음(그날은 K보다 많은 종목을 나눠 보유).
  - 무작위 바구니: 같은 결정일·같은 자격(filter·score 값)·같은 종목 수, 동일가중, 같은 노출·엔진·비용·세금·상폐 분류 규칙으로 200개(씨앗 고정).
    **설계와 다른 점**: 매번 새로 뽑으면 이름 회전이 ~95%라 비용·세금을 전략보다 훨씬 많이 내서 어떤 전략이든 좋아 보임 →
    직전 바구니에서 **전략이 남긴 종목 수만큼**(아직 자격 있는 것 중 무작위) 남기고 나머지만 새로 뽑아 회전을 맞춤.
    `상위 p%` = 1986~2014 세후 보수 CAGR이 무작위 바구니 중 위에서 p% 자리, 95%선·99%선 = 그 백분위를 넘었는지.
  - Sharpe = 1986~2014 보수 행의 **비용 뒤·세금 전** 일간 수익에서 T-bill을 뺀 연율 Sharpe. G1 비타이밍 관문 1.1 이상이면 통과.
  - **MS1(수익 흐름 재표본)** = 보수 행(상폐 분류 규칙)의 **비용 뒤·세금 전 일간 수익 흐름**(실제 날짜, 1970-01-02 첫 편입일부터; `else`
    ETF가 늦게 시작하거나 게이트·신호 준비일이 늦으면 그날부터 — 그 전엔 게이트·신호가 강제로 현금이라)을 `ms1.measure_series`로 MS1 다섯 기준에 다시 표본
    (IS1 방법, 경로 재계산 없음, 아래 MS1 절). 세금은 MS1 쪽 규칙(252일마다 22%, 250만 공제, 실현 몫 = min(1, 편도 연 회전)),
    진입·청산 비용 0.3%. 경로 = dev250_path 중앙값(대표값), 하한 = min(경로, 실제 NDX 86~14). 흐름이 1970년부터라 S&P 70~85는
    계산되고 S&P 55~85는 None(덮음 <95%); 게이트가 있는 명세(lab `_NDX`가 1985-10부터, 준비일 1986-07)는 S&P 두 기준 모두 None
    (흐름이 덮지 못한 날은 수익 0).
    다섯 기준 전체·덮음 비율은 상세 JSON의 `std.ms1`.
  - **G1** = 위 Sharpe 줄(비타이밍 관문). `exposure` 게이트가 있으면 **게이트 신호에도 gate.test**: 게이트를 `QQQ: <exposure>`,
    나머지 현금인 ETF 명세로 바꿔(`stocks.gate_spec`, `exposure_every: rebalance`면 같은 주기 `rebalance:`) ETF 명세의 G1과 같은
    실제 틀(NDX 1986~2014 / S&P 1955~1985)에서 계산 → `G1 게이트 NDX a(상시b) SPX c(상시d) 보정 e N=n 판정`. 게이트가 나스닥100·
    QQQ/QLD/TQQQ·`macro(k)` 밖을 읽으면 `G1 게이트 해당 없음 (읽는 계열 ...)`. 게이트 식에 `macro(k)`도 씀(개발 = 실제 경보).
  - 상세(모든 행, 1971 구간, 무작위 200개 CAGR, 극단 20개, 마지막 결정일 종목)는 `LAB_HOME/out/<hash>_<bar>.json`. 종목은
    **시점 ID**로 찍음(`S0001`..: 첫 편입일 순, 같은 날 편입은 씨앗 고정 추첨; v1·v2 모두 같은 ID): 출처 기호는 2014년 뒤 사실을
    담아(위 자료 항목) 어떤 출력에도 안 나옴. 해시·계열 N에 `universe`·`stock` 포함, `grid:`로 stock 값도 훑을 수 있음.
- **한계**: S&P 500 편입 종목만(소형주·편입 전 종목 없음), 재무자료 없음(가격만; 거래대금은 누출이라 못 씀), 1996~2000 crsp-patch 행 약 0.9%는
  다른 출처와 1%p 넘게 다름(어느 쪽이 맞는지 미확정), 수정가격만 있어 **실제 거래가격 수준 필터(저가주) 불가**, 거래대금·첫 가격
  날짜·편입 전 가격은 누출이라 못 씀(위; 그래서 편입 첫해 종목은 252행 창 값이 없음), 260행보다 긴 창은 lab 상한. 상폐 분류는 가격만 보는 대용(실제 상폐 사유·지급액 없음): 250일 −30% 미만인 인수, −30% 이상인
  부실 상폐는 잘못 분류됨(스트레스 행 일괄-30%·극단으로 확인). 거래정지 구간 안에서 고른 종목은 재개 전엔 못 사 그 몫이 현금
  (정지 중 이어 붙인 가격은 변동성 0이라 저변동 전략이 고를 수 있음; 6건뿐). 전액 손실 종목은 팔 값이 없어 세금 상계가 마지막
  청산으로 밀림(엔진 규칙), 거래정지 중인 종목도 다른 종목 거래 비용을 비례로 나눠 냄. 한 명세 약 10~25초(첫 패널 읽기 약 6초 별도,
  MS1 흐름·G1 게이트 1~2초 더). **연속(분수) 노출**(예 `exposure: 'min(1, 0.15 / vol(_NDX, 20))'`)은 노출이 매일 바뀌어 모든 장부
  (무작위 200개 포함)가 매일 거래 → **명세당 약 80초**(격자 10점 ≈ 14분): `exposure_every: rebalance`(결정일에만 노출을 정함)를 쓰면
  10~25초. MS1 흐름은 개별 종목을 경로마다 다시 고르지 않음(흐름 자체를 재표본) — ETF 명세의 MS1(경로마다
  명세 재계산)과 뜻이 달라 표시도 `MS1(수익 흐름 재표본)`.
- 예시 `specs/examples/stk_*.yaml`: `stk_mom12_1_top20`(12-1 모멘텀 상위 20), `stk_lowvol_top50`(저변동 50, 역변동성 비중, 분기),
  `stk_mom_trend_gate`(모멘텀 20 + _NDX > SMA200일 때만, 아니면 현금), `stk_quality_proxy`(가격만으로 만든 품질 대용: 추세·저변동·
  고점 근접 순위 합, 상위 30), `stk_regime_switch`(`_SP500EW` > SMA200이면 12-1 모멘텀 20, 아니면 저변동 20, 늘 투자, 1970-11 준비).

## DSL 요약표 (v2)
식은 문자열, 이름은 상품명(`QLD`)이면 그 **기초지수**(QLD→나스닥100), 따옴표/패널 이름(`'KRW_X'`, `_IRX`)은 그 시계열,
`_SP500EW`는 개별주 패널의 시점별 동일가중 편입 종목 지수(위 개별 종목 절; 판정·MS1 경로엔 없음).
창·지연·기간 인자는 정수 ≥1만(0·음수 = 미래 행 → 오류). `and or not`, 비교 연쇄, `+ - * / % **`, 이름 목록 `[QLD, TLT]`만 허용.

| 함수 | 뜻 |
|---|---|
| `price(x)` `sma(x,n)` `ema(x,n)` `ret(x,n)` `vol(x,n)` `high(x,n)` `low(x,n)` `dd(x,n)` `rsi(x,n=14)` | 기본 지표 (vol = 연율 로그수익 표준편차) |
| `month()` `weekday()` `min(a,b)` `max(a,b)` `abs(a)` `lag(s,n=1)` | 달력·산술·지연 (합성 경로에서 달력은 의미 없음) |
| `latch(on, off)` | on이면 켜짐, off면 꺼짐, 아니면 유지. 처음 꺼짐, 같은 날 둘 다면 off |
| `corr(x, y, n)` | n일 상관 (이름 = 일간 로그수익, 식 = 그대로) |
| `zscore(s, n)` | (s − n일 평균)/n일 표준편차 (이름 = 가격) |
| `ewvol(x, halflife)` | 지수가중 연율 변동성 (halflife > 0) |
| `since(cond)` | cond가 마지막으로 참이던 날부터 지난 날수 (참인 날 0, 한 번도 없으면 inf) |
| `hold_min(cond, n)` | cond가 켜진 날부터 최소 n일 켜둠, 그 뒤엔 cond 따라감 |
| `invvol(x, [a,b,..], n)` | 목록 안 역변동성 비중 중 x의 몫 (변동성 = 배율 × 기초지수, 합 1) |
| `rp(x, [a,b,..], n)` | 위험균형(위험기여 같게) 비중 중 x의 몫 (n일 공분산, 음의 상관도 정확히 풂: 두 상품이면 invvol과 같음) |
| `level(x)` | 보유 상품 x의 **거래 가격 수준**(개발 = 상장 전 합성 포함 누적 수익, 판정 = 경로의 x 가격). 비율로만 쓸 것, 예 `level(TQQQ) / high(level(TQQQ), 252)` |
| `macro(k)` | MS1 거시 경보 8개 중 하나(참/거짓): `inv` `inv2`(장단기 역전 378/504일 안) `shock` `shock10`(10년물 1년 +1.5/+1.0%p) `shock6m` `shock6m75` `shock3m`(6개월 +1.0/+0.75, 3개월 +0.75%p) `csj`(신용 스프레드 급등). 개발 = 실제 경보(`lab/macro_flags_le2014.csv.gz`, ≤2014, `tools/build_macro_flags.py`), MS1 경로 = 그 기준의 경보, 판정 경로엔 없음 → `REJECT (version impossible)`. `macro(inv)` = `macro('inv')` |

invvol·rp는 목록의 **모든** 상품에 n일 변동성이 생긴 날부터 값이 있음(그 전엔 0). 지표 함수(`sma` `high` `dd` `vol` …)의 첫 인자는
이름 또는 식(예 `sma(level(TQQQ), 50)`). 상수 계산은 실수로 해서 `10**10**9` 같은 식은 바로 오류. 신호 이름은 식별자만:
YAML은 `on` `off` `yes` `no`를 참/거짓으로 읽으므로 신호 이름으로 못 씀(`latch(go, stop)`처럼).

**규칙** (`rules`, 위에서부터 처음 맞는 것): `- when: 식` + `hold: {상품: 비중식}` / `- else: {..}`(else 줄엔 다른 키 없음) /
`- [when: 식] rotate: {..}`. 비중 합 >1이면 1로 줄이고 나머지는 CASH.

**rotate** — `assets: [..]`(필수), `score: 식`(`*` = 각 상품, 예 `ret(*, 126)`), `filter: 식`(`*` 사용),
`top: k`(score 있으면 기본 1, 없으면 전부), `weight: equal|score|invvol|rp`(기본 equal; score = 양수 점수 비례),
`n: 60`(invvol·rp 기간), `every: daily|weekly|monthly|quarterly|N`(기본 monthly, 기간 **첫 거래일**에 결정),
`exit: daily`(결정일 사이 filter 깨지면 그날부터 다음 결정일까지 뺌), `total: 0.88`(합, 기본 1),
`fill: 상품`(빈 자리 몫, 기본 CASH). 고른 수 m < k이면 총합 × m/k만 담고 나머지는 fill.

**전체 후처리 순서**: 규칙(또는 plugin) → 합 ≤1 → `rebalance`(daily|weekly|monthly|quarterly|N, 기간 첫 거래일 표본)
→ `brake` → `band`.

**brake** (자기 장부 낙폭 제동) — 장부 = 전략 자신의 비중(전날 결정) × 상품 종가-종가 수익, **비용·세금 없음, 현금 수익 0**,
첫 행부터(판정 경로는 워밍업 300일 포함; G0 상한 축소 전 비중). t일 비중은 t일 종가까지의 장부만 씀(인과).
- `{dd: -0.20, scale: 0.5, recover: -0.10}` 낙폭 ≤-20%면 0.5배, -10% 이상 회복하면 복귀 (recover 기본 dd/2)
- `{ladder: [[-0.10, 0.75], [-0.20, 0.4], [-0.30, 0.0, -0.12]], recover: -0.05}` 단계별(각 단계 [dd, 배수(, 복귀)]), 가장 작은 배수
- `{knee: [-0.45, -0.75], floor: 0.0}` -45%부터 -75%까지 선형으로 1→floor (복귀 지연 없음)
- 공통: `basis: own|raw`(own = 제동된 자기 장부, 기본; raw = 제동 전 장부), `cooldown: N`(N일 넘게 제동이면 풀고 고점 재설정
  — own + scale 0은 장부가 멈춰 영영 안 풀리므로 이걸 쓰거나 raw), `floor_when: {when: 식, scale: s}`(그날 최소 배수).
- 경로당 계산 ~1–2ms(10년+워밍업 2821행), 경로당 전체 비중 계산 ~2–3ms.

**grid** — `grid: {X: [0.25, 0.30, 0.35]}` + 명세 어디든 `{X}`. 점마다 별도 명세(이름 `base[X=0.25]`, 해시 따로,
원장에 따로, **계열 N에 각각 셈**). 값 전체가 `'{X}'`면 숫자 그대로. 키 여러 개면 곱집합(최대 256점).
`name` `family` `known` `baseline`에는 `{X}`를 못 씀(점마다 계열이 갈리면 N을 못 셈).

**plugin** (DSL로 **못 쓰는 모양**에만) — `plugin: plugins/f.py:func`(명세 파일 기준 경로), `sleeves: [..]`(필수),
`inputs: [QQQ, 'level(TQQQ)', 'vol(QQQ, 20)']`(F의 열: 이름 = price()와 같은 뜻, 그 밖은 DSL 식; 열 이름 = 그 문자열),
`params: {..}`. `func(F, sleeves, params)` → F와 같은 index, 열 ⊂ sleeves+CASH인 비중 DataFrame. 개발 요약과 판정 경로마다 실행,
후처리(rebalance·brake·band) 동일. 해시 = 파일 내용.
- **격리**(`lab/sandbox.py`): plugin 코드는 lab·판정 프로세스에서 **실행되지 않음**. 작업 프로세스마다 numpy·pandas만 올린 별도
  인터프리터를 띄우고, 호출(세션)마다 거기서 새 자식 프로세스를 fork. 자식은 받은 F만 가짐(패널·lab·blackbox 없음), 파일·소켓을
  새로 못 엶(RLIMIT_NOFILE), root면 nobody로 내려감(lab에 신호 못 보냄), fork 불가, CPU 제한, 프레임당 120초 시간 제한
  (`LAB_PLUGIN_TIMEOUT`). 모듈 상태는 호출 사이에 안 남음. 결과는 JSON + 숫자 버퍼로만 받음(pickle 안 씀).
  `SystemExit` 등 무엇을 던져도 그 명세의 `PluginError` 한 줄이고 배치는 계속.
- 소스 검사(빠른 오류용): import는 numpy pandas math itertools functools collections statistics bisect heapq operator re만,
  `__x__` 이름 금지, open / np.load / os / sys / /mnt … 금지.
- 인과성: 세션 안에서는 **앞 프레임을 늘인 프레임**만 같은 자식에 보냄(가진 상태 = 이미 받은 행뿐). 절단 시험은 짧은 것부터,
  전체를 마지막에 보내므로 저장해 둔 전체 답을 잘린 호출에 되돌려 주는 수법이 안 통함. plugin은 경로당 무작위 300곳 + 경계 절단.
- 비용: 판정 경로 1개 계산마다 fork 1번(~10ms). quick은 몇 초 늘고, full(판당 경로 수만 개)은 4 작업자 기준 판당 수 분 늘 수 있음.

**판정 경로가 재표본하지 않는 입력**(`_IRX` 등 거시, `macro(k)`, `*.KS`, `KRW_X`, GLD·SHY 같은 대용 없는 상품)은 식·rotate·목록·

## MS1·G1 자동 보고 (`--std auto`, 기본)
프로젝트 고정 측정 기준 **MS1**(`research/measure_std/MEASURE_STD_KO.md`, `std.py`)과 정보량 관문 **G1**
(`research/breakthrough/INFO_GATE_KO.md`, `code/gate.py`)을 lab이 자동으로 재서 한 줄에 붙임. 모두 개발 구간(≤2014) 숫자.
```
MS1 경로 5.7% (하한 5.7%, s0.85 16.2·1x 11.6) dd80 98% s0.85대비 -10.3%p 승 6% §5엔진 | G1 NDX 52.9(상시55.5) SPX 53.0(55.7) 보정 47.5 N=1 닫음 CLOSE
```
- **MS1**: 경로 = dev250_path 30년 세후(청산세 포함) 연복리 중앙값(MS1 대표값). 하한 = std.measure의 `FLOOR_MS1`
  = min(dev250_path, 실제 NDX 86~14). 괄호 안 = 같은 기준의 s0.85·1배 보유. dd80 = 경로 중 MDD ≤ −80% 비율.
  s0.85대비 = 같은 경로끼리 짝지은 차이의 중앙값(%p), 승 = s0.85를 이긴 경로 비율. 다섯 기준 전체(glued, 실제 NDX,
  S&P 55~85·70~85, 1·2·3배 보유, 연 거래 수)는 `LAB_HOME/out/<hash>_<bar>.json`의 `std`.
- **G1**: 실제 나스닥100 1986~2014 / S&P500 1955~1985 21일 블록 적중률(괄호 = 늘 들고 있기 적중), 보정 = 낮은 시대의
  적중 − 2·SE·√(1+ln N)(N = 원장의 계열 시도 수), 판정 `닫음 CLOSE` / `보류 HOLD` / `설계 BUILD` / `60%후보 60%-CANDIDATE`.
  시장 안 = 종가 t의 위험 비중 합 > 0. 명세를 실제 전체 틀(NDX 1984~2014, SPX 1928~1985: SPX 수준을 `_NDX` 자리에, 상품은
  SPX 수익으로)에서 계산하고 1986-01-01 전은 SPX 신호, 뒤는 NDX 신호. 한 시대라도 늘 안(또는 늘 밖)이면
  `G1 해당 없음 (상시 보유)` + 비용 후·세전 연 샤프(실제 NDX 86~14·S&P 55~85 중 낮은 쪽) vs 1.1 — INFO_GATE의 MS1 기준 샤프
  (0.55 등)와 정의가 달라 섞지 않음.
- **자격**: `account: us`, 보유 ⊂ {QQQ, QLD, TQQQ, CASH}, 읽는 계열 ⊂ {QQQ, QLD, TQQQ, _NDX} + `macro(k)`. 그 밖은
  `MS1: 해당 없음 (이유)`(예 `보유 SSO,TLT: QQQ·QLD·TQQQ·CASH만`). plugin 명세도 됨(경로마다 격리 실행이라 느림).
  개별주 명세(`universe: sp500`)는 경로마다 다시 계산하지 않고 **수익 흐름 재표본**(아래 `measure_series`)으로 늘 계산
  (`MS1(수익 흐름 재표본) 경로 x%`, 위 '미국 개별 종목' 절), G1은 Sharpe 줄 + 게이트가 있으면 게이트의 gate.test.
- **엔진 = MS1-조건 sleeve 엔진** (`lab/ms1eng.py`, 줄 끝 `§5엔진`): std.measure의 엔진은 수준 L을 TQQQ L/3 + 현금으로 들어서
  QQQ·QLD 명세엔 틀린 값을 냄(B=1 → 2.9%, 1배 보유 11.6%가 아님). 그래서 명세의 QQQ·QLD·TQQQ·현금 비중을 그대로 거래하는
  엔진을 따로 두고 beng(= std.engine)의 1장 조건을 그대로 씀: 편도 0.3%, 해마다(252일) 실현 순이익 − 250만(시작 1천만 → 0.25)의
  22%를 비례 매도로 납부, 이월결손 없음, 해 끝에 공제만큼 이익(또는 초과 실현이면 손실) 실현(beng harvest), 마지막 날 청산세,
  2·3배 = L·r − (L−1)·rf − 2.45%/년, 1배 0.2%/년, 현금 (rf − 2%p)·(1 − 15.4%), 체결 지연 2, 나스닥100 가격지수, 다섯 기준
  (std.contexts() 그대로). MEASURE_STD_KO.md 5장이 허용하는 '1장 조건·2장 기준이 같은 별도 엔진'.
  명세는 경로마다 lab DSL 그대로 계산: `_NDX` = 경로 지수, 보유 상품 수준 = MS1 비용 수익(level(x)·brake), `macro(k)` =
  그 기준의 경보(dev250_path = 경로 위 재계산, glued = 원래 날짜, 실제 기준 = 실제), month()/weekday() = 경로 행의 원래 날짜.
  명세의 cost·delay는 안 씀(MS1 0.3%·지연 2), `rebalance:` 표본일엔 목표로 되돌려 거래, 수준 반올림 없음(비중이 바뀌면 거래).
- **일치 시험** (`tests/test_ms1.py`):
  - TQQQ 상수 = MS1 3배 보유 행, 다섯 기준 모두 정확히(4.23 / 4.23 / 3.87 / 9.84 / 4.35).
  - TQQQ+현금 명세 = 같은 명세의 std.measure와 정확히 일치: trend_tqqq_200(경로 5.73, 실제 NDX 6.08, S&P55 11.56),
    macro 경보 명세(경로 10.77, glued 22.57), TQQQ 0.5. **연속 비중**(변동성 비례 TQQQ)은 경로 11.15 vs 13.46: beng은 수준을
    0.1/0.5 단위로 반올림하고 한 단위 넘게 움직일 때만 거래, sleeve 엔진은 비중이 바뀔 때마다 0.3%로 거래(연 250회) —
    순서 단위 규칙 차이. 연속 비중 명세는 `band:`로 거래를 줄일 것.
  - QQQ·QLD 상수 vs std.hold 1·2배 행: 세전 곡선은 정확히 비례(수익 공식 일치). 세후 차이(경로 / glued / 실제 NDX / S&P55 / S&P70):
    1배 +0.07 / +0.07 / +0.13 / +0.01 / +0.58%p, 2배 +0.12 / +0.12 / +0.24 / +0.06 / +0.43%p. 이유: std.hold의 1·2배는 공제 없이
    마지막에 한 번 과세하는 별도 식이고, sleeve 엔진은 s0.85·3배 행과 같은 beng 규칙(해마다 250만 공제만큼 이익 실현)을 씀.
    그래서 이 두 행은 0.05%p 안으로 안 맞음(숨기지 않음). 공제 효과는 수익이 낮은 시대(S&P 70~85)에서 큼.
  - `measure_series`에 나스닥100 1배 흐름(0.2%/년, 회전 0) → 1배 보유 행과 경로 −0.007, 실제 NDX −0.006%p.
  - G1 자체 점검: 늘 안 55.46 / 55.68 닫음, 미래 오라클 1.0, SMA200(trend_tqqq_200) 52.87 / 52.97 닫음.

  같은 경로 색인 행렬로 다시 표본(IS1 방법, research/indiv_stock/code/bases.py + eng.py), s0.85와 경로별 짝. 세금 = 252일마다
  22% × max(min(1, 회전) × 미실현 이익 − 0.25, 0), 이월 없음, 진입·청산 비용 0.3%, 청산세. 흐름이 덮지 못하는 기준(사용 날의
  95% 미만, 예 1986년 이후 흐름의 S&P 시대)은 None. 2014-12-31 뒤 행은 버림. 표시 `MS1 (수익 흐름 재표본, 경로 재계산 없음)`.
- **준비**: `python3 -B -m lab setup` → `LAB_CACHE/ms1-venv`(기본 `~/.cache/lab/ms1-venv`, PyPI에서 numba scipy xlrd numpy
  pandas pyyaml, 1~2분, 약 500MB). 없으면 `lab run`이 한 번 알아서 설치(`MS1 계산 환경 설치 중 ...` 한 줄), 실패하면

  작업자 프로세스 1개(`lab/ms1.py serve`)에서만 돎(모듈 이름 충돌 방지).
- **버전 고정**: std.py sha256 앞 12자리 `ee4de887037c`, gate.py `8bf8531428cb`가 아니면 `MS1 기준 변경됨`(숫자 없음).
- **속도**: 작업자 시작 처음 한 번 ~30 s(numba 컴파일·s0.85 기준값 저장), 그 뒤 ~10 s(개발 요약과 겹쳐 돎). 명세당 1~12 s

  계산. 결과는 원장에 (해시, 엔진 버전 + std/gate sha)로 저장 → 다시 돌리면 즉시(G1 보정은 그때의 N으로 다시 계산).
