# MX1 (2026-11-12)

여러 시장 합동 대규모 탐색: 규칙 64억 개(평가 1.1e11), 노출 중립 시점 z, 위약 300회 보정.

결과: v1을 넘는 규칙 0개. 발견 구간 정보는 우연과 구별 안 됨(클래스2 p1 .385, p2 .236). 확인 구간(2000~14) 후보 60개 중 합동 z 통과 15개이나 NDX 3배 성장 음수, 1배/현금형 최고 5.3%/년. 탐색 상위 규칙의 98% 이상이 금리 원자(v1 경보 계열)를 포함. v1 기대는 연 15.2%(경로 중앙값, 쉬는 돈 이자 0) 그대로.
