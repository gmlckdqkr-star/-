신호가 켜진 블록은 76개였다(기준 8개 이상은 충족). on 블록의 적중률은 47.4%로, 시대별 base(가중 55.6%)보다 **8.2pp** 낮았다.
기준은 10pp 이상이므로 미달이다. 사전 등록대로 기준을 낮추지 않고 멈췄다. 미공개 구간(2000-2014)은 열지 않았고 measure2도 돌리지 않았다.

## 검증
- 시점 규칙: 월별 값(m월)은 m+1월 첫 거래일부터, ECB 일별 값(d일)은 d 다음 거래일부터 사용하고 거래일로 ffill했다. 정책금리 결정은 발표일에 공개되므로
  공개 정보 기준으로는 보수적이다(IMF/OECD 배포 지연 기준으로는 낙관적). 2011년 이전 ALFRED 빈티지가 없어 최초 발표값은 확인하지 못했다.
- 독일 1957-1998은 ALFRED 2014-12-31 빈티지(현재 FRED INTDSRDEM193N은 재정의되어 사용 안 함). ECB MRO 공백(2000-06-28..2008-10-14)은 ECBDFR+통로로 채운 파일 사용.
  영국 IFS 값과 BOERUKM의 차이는 소수 둘째 자리 반올림뿐(최대 0.005pp). 이음점 변화(일본 1985-07, 독일→ECB 1999-01)는 0으로 처리했다.
- 벡터화한 신호를 원천 변화 이벤트를 직접 더하는 반복문으로 다시 계산해 초기 블록 478개 날짜 전부 일치(불일치 0, results/s3_check_early.json).
- 블록·라벨은 gate._frame 그대로(3x 상품 3r-2rf-2.45%/년 vs 예금 (rf-2pp)×0.846, t+3..t+23). 라벨이 2000년으로 넘어가는 1개 블록은 초기 구간에서 뺐다(사전 등록).
- v1 목표는 L.v1_B를 real 문맥과 같은 방식으로 만들어 썼다. NDX 1986-99 v1 일별 비중: 3x 80.8%, 1x 10.5%, 현금 8.7%.
- N = 1(변형 1개, 임계값·창·국가 조합·'1곳 이상' 변형 없음). sqrt(1+ln N)=1이라 축소 보정은 없고, 보정과 무관하게 FAIL이다. 2014년 이후 값은 읽지 않았다.
