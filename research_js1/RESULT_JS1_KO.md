## 결론
- **v1 방법은 바꾸지 않는다. 계획 수치 15.2% 그대로.** 사전 사다리(L1 합동 확인 + L2 미국 v1 덧씌움)는 규칙 5개(서로 비슷한 3가지 모양)가 기계적으로 통과했지만, 정보 판정은 "우연과 구별 안 됨"이고 통과 이유가 약해(아래) 적용·후보 승격하지 않는다. 통과 숫자를 성과로 인용하지 않는다.
- 새 정보군(민간 신용 양, 주택, 화폐, 가치)에는 독립 정보가 없었다. 통과 규칙의 실체는 또 "세계 금리·기울기 경보"(v1이 이미 쓰는 계열)다.

## 규모

## 결과
- **정보 판정(계급 2, 설계 구간 1871~1985)**: 부분집합 진짜 최고 z 지도0 7.48 / 지도1 7.99 vs 위약 200회 최고 z 중앙 7.38 / 7.19(95% 10.4). z ≥ 3.5 개수 진짜 18.5만 / 24.7만 vs 위약 중앙 21.0만 / 13.8만. p1 = .46/.37, p2 = .51/.45 → **우연과 구별 안 됨**(기준 ≤ .025). 전수·무작위 전체 최고 z 7.65~8.25(위약 최댓값 11.4까지 나옴: 지도 간 얽힘·세계 원자 때문에 꼬리가 매우 두꺼움).
- **연간판 v1 경보(참고)**: OFF=기울기 역전 설계 z 1.7~2.0(확인 0.7), OFF=금리 +1%p 3.2/3.0(p .03~.045, 확인 0.6), 둘 합 2.8/2.9(p .025~.04, 확인 0.3), 추세형 4번째 설계 z 6.7(위약 p .005)이나 확인 −1.1(부호 반대). 즉 경보 정보는 설계 구간에 약하게 있고 확인 구간(1986~2014)에선 거의 안 보인다.

## 왜 채택하지 않나 (추론 + 확인)
1. 정보 판정 p .37~.51: 이 크기 공간의 최고 z는 위약에서도 나온다. 통과는 선택 효과일 가능성이 큼(확인됨: 위약 대비 순위).
2. 경로 +4~7%p는 부풀려진 값일 가능성이 높다(추론): 연간 상태를 원천 행 날짜로 옮기면 블록을 섞어도 2000~02·2008 하락 날짜를 정확히 아는 마스크가 된다. v1 자신의 느린 경보는 경로에서 약해진다(경로 15.2 vs 붙인 26.4, 기록). MX1이 "경로 미측정"으로 둔 이유와 같다. 실제 NDX는 +0.3~1.7%p로 한두 번의 사건 범위.
3. 규칙 실체 = 세계 기울기/금리 경보(OFF 특징 해 1989~90, 2000~01, 2006~07 = v1 경보 시기). 새 정보가 아니라 v1 경보의 세계판 반복이며 MX1·GX1 결론(금리 곡선 계열만 정보)과 같다.
4. 미국 S&P 55~85·70~85에서 −3~−8%p: 일반화 근거 없음.
