## 2. 결과·지도 (고정)
수익 r = JST eq_tr(t+1)(현지 통화 명목, 배당 포함), b = bill_rate(t+1).
- 지도 0 (3배 vs 1배): x = ln(max(1e-4, 1+3r−2b−0.0245)) − ln(1+r−0.002)
- 지도 1 (3배 vs 현금, 쉬는 돈 이자 0): x = ln(max(1e-4, 1+3r−2b−0.0245))
- 지도 2 (1배 vs 현금, 보조): x = ln(1+r−0.002)
켜짐 = 앞 상품(3배 또는 1배), 꺼짐 = 뒤 상품. 주 판정은 지도 0·1.

## 4. 규칙 공간·통계 (고정)
- 규칙 = 원자 1~3개 전수(AND/OR 8가지 모양, 약 1.9×10^9) + **무작위 1×10^10**(크기 2/3/4 = 10/40/50%, 4개짜리 6가지 모양, seed 777, 스레드별 시드 파생). 모양: 1개 A; 2개 A&B, A|B; 3개 A&B&C, A|B|C, A&(B|C), B&(A|C), C&(A|B), A|(B&C), B|(A&C), C|(A&B); 4개 A&B&C&D, (A&B)|(C&D), A&B&(C|D), A&(B|C|D), A|B|C|D, (A|B)&(C|D).
- 통계 z = Σ_c skill_c / √Σ_c var_c, skill_c = Σ_{켜짐 관측}(x − x̄_c) − 비용×전환수, var_c = p_c(1−p_c)·n_c/(n_c−1)·Σ(x − x̄_c)², p_c = 나라 c 켜짐 비중(노출 크기가 곧바로 점수가 되지 않음). 전환 비용 지도0 0.6%, 지도1·2 0.3%(전환 = 연속한 두 해 사이 켜짐 상태 변화). 켜짐 관측 30 미만 또는 꺼짐 30 미만이면 제외. **주 판정 계급 = 켜짐 비중 ≥ 50%**(상시 보유형: v1처럼 위험할 때만 빠짐)만 평가.
- 규모 표기: 규칙 약 1.2×10^10, 지도 3 → 평가 약 3.6×10^10, 위약 포함 약 6×10^10. 유효 독립 수는 훨씬 작다.

## 5. 위약·정보 판정 (고정)
- 위약: 설계 구간 결과 x를 특징에 대해 연도로 원형 이동(이동 5~110년, 모든 나라 같은 이동 = 나라 간 동시 위기 정렬 보존, 시드 1000+p), 이동 후 빈 값은 그 나라 평균. 부분집합 S = 무작위 규칙 1×10^8개(seed 20261112, 위 크기 비율) × (진짜 1 + 위약 200).
- **정보 판정**: 계급 2, 지도 0·1에서 T1 = z 최댓값, T2 = z ≥ 3.5 평가 수. p = (1 + 위약 중 ≥ 진짜)/201. min(p1, p2) ≤ 0.025이면 "표본 안 정보 있음", 아니면 "우연과 구별 안 됨"(그대로 결론에 씀).
- 참고 규칙(탐색 아님, 후보 아님; 위약 200회와 같은 방법으로 p 보고): 연간판 v1 경보 4개: OFF=기울기<0(t 또는 t−1) / OFF=장기금리 +1%p / OFF=둘 중 하나 / OFF=(주식 1년 수익<0)이면서 둘 중 하나.

## 6. 확인 (한 번만)
- 후보 = 진짜 전수+무작위에서 계급 2, 지도 0·1 각각 z 상위 20개(설계 구간 켜짐 패턴이 같은 규칙은 하나로) = 최대 40개. 정보 판정이 "구별 안 됨"이어도 확인은 한 번 한다("추가 진단", 선택 정당화에 쓰지 않음).
- **L1 (합동 확인)**: 확인 구간(1986~2014, 나라별 평균은 확인 구간 안에서) 같은 z 식 ≥ 3.0(= 40개 본페로니 .05 단측) AND 켜짐-꺼짐 skill > 0인 나라가 전체의 62.5% 이상.
- **L2 (미국 v1 덧씌움, L1 통과 후보만; 통과 0이면 확인 z 상위 3개를 "추가 진단"으로만 쟀다고 표기)**: 미국 특징 해 f의 켜짐/꺼짐을 달력 날짜 d에 적용(f = (d의 연도, 4월 이후면 그 해, 아니면 전년) − 1; 즉 발표 지연 3개월 보수 적용). 꺼짐일 때 지도0 후보는 v1 목표 B = min(B, 1), 지도1 후보는 B = 0. 엔진: MS1 std.engine(v1과 같은 F1 비용·세금·브레이크·cspr 10, 쉬는 돈 이자 0), 문맥: real_ndx_86_14, dev250_path(경로: 원천 행 달력으로 상태 이식, GX1 방식), real_spx_55_85, real_spx_70_85. 통과 = real_ndx_86_14 연복리 > v1(30.53%) AND dev250_path 중앙 > v1(15.18%) AND 짝 이긴 경로 비율 ≥ 55% AND dd80(경로) 증가 ≤ 5%p. S&P 값은 보고만(설계 구간과 겹침).
